# سياسة حوكمة الصلاحيات وفصل المهام — CORVAX RC5

## المبادئ

- يتم فحص الصلاحيات المجمعة للمستخدم داخل الشركة، وليس اسم الدور فقط.
- التعارضات الحرجة يجب إزالتها أو توثيق ضابط مخفف وموعد معالجة.
- لا يجوز للمستخدم مراجعة صلاحياته بنفسه.
- لا يجوز لمن أنشأ حملة مراجعة الوصول أن يعتمدها.
- لا تعتمد الحملة مع وجود عناصر معلقة.
- قرار REVOKE يطبق على عضوية الدور عند اعتماد الحملة.
- تحتفظ المنصة بأثر قرار المراجعة وسجل التدقيق بعد سحب الدور.

## قواعد SoD الافتراضية

- إنشاء القيود مقابل اعتمادها.
- إنشاء القيود مقابل ترحيلها.
- إعداد الرواتب مقابل صرفها.
- إعداد الموازنة مقابل اعتمادها.
- إدارة الصلاحيات مقابل اعتماد مراجعتها.
