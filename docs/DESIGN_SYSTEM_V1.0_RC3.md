# CORVAX 2026 Design System — RC3

## الاتجاه المعتمد

واجهة مؤسسية فاتحة ومريحة للعين، مع شريط جانبي كحلي هادئ ولمسات ذهبية محدودة للهوية فقط. لا تستخدم الخلفيات الداكنة الكاملة في الاستخدام اليومي الطويل.

## الألوان

- خلفية التطبيق: `#F5F8FC`
- سطح البطاقات: `#FFFFFF`
- الشريط الجانبي: `#15395D` إلى `#102E4C`
- النص الرئيسي: `#102A56`
- الأزرق الأساسي: `#2F74DD`
- الأخضر: `#25A55F`
- التركوازي: `#2BA7A1`
- البنفسجي: `#7D58D8`
- البرتقالي: `#EFA327`
- الذهبي للهوية: `#D5A94E`
- الأحمر للمخاطر: `#E45555`

## الخطوط

- العربية: Alexandria عند توفرها، ثم Segoe UI وTahoma.
- الإنجليزية: Inter عند توفره، ثم Segoe UI وArial.
- لا يتم تضمين ملفات خطوط داخل الحزمة.

## مكونات منفذة

- App Shell وشريط جانبي ثنائي اللغة.
- Global Search وApplication Header.
- KPI Cards مع Sparkline.
- Financial Performance Chart.
- Expense Donut.
- Alerts and Notifications.
- Receivables/Payables Ageing Cards.
- Cash Flow Card.
- Quick Actions.
- Governance Status Strip.
- Login Experience.
- Company Selector.
- Light/Dark Theme.

## قواعد الاستخدام

1. الذهب للهوية والتأكيد، وليس كلون تشغيل أساسي.
2. اللون الأحمر للحالات الجوهرية فقط.
3. كل رقم مالي يجب أن يكون قابلًا للتتبع إلى مصدره.
4. الجداول يجب أن تحافظ على كثافة مناسبة للمحاسبين.
5. جميع الشاشات تُبنى عربي/إنجليزي وRTL/LTR منذ البداية.
