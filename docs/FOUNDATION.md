# CORVAX Business Platform Foundation v0.1

## Adopted principles
- Arabic and English from day one with RTL/LTR support.
- True multi-company architecture.
- Financial, operational, audit and reporting separation.
- Configurable branding per company.
- PostgreSQL-ready backend.
- Audit trail, workflow and permissions to be added as core services.

## First implemented slice
- FastAPI backend health endpoint.
- Companies API.
- Bilingual company selector.
- Comfortable light visual system using Alexandria/Inter fallbacks.
- Responsive desktop/mobile layout.

## Next implementation slice
1. Authentication and tenant context.
2. Company profile and branding persistence.
3. Roles and field-level permissions.
4. Fiscal years and periods.
5. Chart of accounts foundation.
6. Immutable audit log.
