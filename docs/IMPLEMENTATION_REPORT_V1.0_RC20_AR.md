# تقرير تنفيذ CORVAX v1.0 RC20
## الواردات والتكلفة والمخزون والموازنات

## 1. القرار الضريبي المعتمد

تم تصحيح تصميم المشتريات الخارجية بحيث لا يخلط النظام بين فاتورة المورد الأجنبي وبين حدث ضريبة الاستيراد في السعودية.

- فاتورة المورد الخارجي قد تُسجل بلا ضريبة قيمة مضافة سعودية.
- البيان الجمركي قد يظهر ضريبة محصلة تساوي صفرًا.
- الصفر في البيان لا يُعامل تلقائيًا كشراء صفري؛ بل يجب تحديد سبب نظامي موثق:
  - الضريبة تُحتسب عبر الإقرار.
  - الضريبة معلقة جمركيًا.
  - استيراد معفى بمستند نظامي.
  - أو أن الضريبة حُصلت فعليًا في الجمارك.
- بلد المنشأ، بما فيه البرازيل، لا يحدد المعالجة منفردًا.

تمت إضافة الأكواد والحالات التالية:

- `PFOR0` — فاتورة مورد أجنبي بلا VAT سعودي.
- `PIMPR15` — ضريبة استيراد محتسبة عبر الإقرار.
- `PIMPS0` — استيراد معلق جمركيًا.
- `PIMPE` — استيراد معفى.
- `AT_CUSTOMS` — الضريبة محصلة في البيان.
- `THROUGH_RETURN` — البيان صفر والضريبة محتسبة عبر الإقرار.
- `SUSPENDED` — تعليق جمركي.
- `EXEMPT` — إعفاء موثق.

كما أصبح التصدير بنسبة صفر مشروطًا باعتماد مستندات إثبات التصدير بدل تصنيفه نهائيًا بمجرد إصدار الفاتورة.

## 2. المشتريات الخارجية والتكلفة الواصلة Landed Cost

تم تنفيذ دورة مستقلة تشمل:

- ربط مستند التكلفة الواصلة بإذن الاستلام والبيان الجمركي.
- فواتير الشحن والتأمين والجمارك والتخليص والمناولة والمصاريف الأخرى.
- فصل التكلفة القابلة للرسملة عن المصروف غير القابل للرسملة.
- عدم تحميل VAT القابل للاسترداد على تكلفة المخزون.
- تحميل الضريبة غير القابلة للاسترداد وفق السياسة المحاسبية.
- التوزيع على أصناف إذن الاستلام وفق:
  - القيمة.
  - الكمية.
  - التوزيع المتساوي.
- إنشاء فواتير الموردين والقيود المحاسبية وحركات قيمة المخزون.
- استخدام حساب وسيط للتكلفة الواصلة حتى اكتمال التوزيع.
- دورة إعداد وإرسال واعتماد وترحيل مع منع الاعتماد الذاتي.

## 3. تفكيك تكلفة المنتج النهائي

تم بناء Cost Explosion متعدد المستويات للـBOM والوصفات، بحيث يفك النظام المنتج النهائي والمنتجات نصف المصنعة حتى المواد الأساسية.

تعرض النتيجة بصورة مستقلة:

- المواد الخام المباشرة.
- مواد التعبئة والتغليف.
- الأجور المباشرة.
- المصروفات المباشرة.
- الـOverhead المتغير.
- الـOverhead الثابت.
- إجمالي تكلفة الإنتاج.
- تكلفة الوحدة.
- التكلفة المعيارية الحالية.
- فرق التكلفة المعيارية.

يدعم المحرك:

- تكلفة معيارية أو متوسط تكلفة فعلي.
- مسارات تشغيل معتمدة.
- وقت الإعداد ووقت التشغيل.
- التشغيل لدى الغير.
- كشف الدوران أو التكرار الخاطئ داخل BOM.
- إعداد ثم مراجعة ثم اعتماد مستقل.
- تحديث تكلفة الصنف المعيارية بعد الاعتماد فقط.
- تصدير تفاصيل تفكيك التكلفة إلى CSV.

## 4. الجرد المستمر والمخزون

تم تعميق الجرد المستمر ليشمل:

- بقاء كل حركة كمية وقيمة في دفتر المخزون المساعد.
- تقرير مطابقة دفتر المخزون مع حسابات المخزون في الأستاذ العام.
- جرد شامل أو Cycle Count.
- تجميد لقطة الكميات الدفترية عند بدء الجرد.
- تسجيل الكميات الفعلية وأسباب الفروق.
- منع وجود أكثر من جرد مفتوح لنفس المستودع.
- اعتماد فروق العجز والزيادة وترحيل قيودها.
- إنشاء حركات تسوية مخزون مرتبطة بالقيد.
- تصنيف المخزون إلى نشط وبطيء الحركة وراكد ومنتهي.
- تخفيض المخزون إلى NRV أو بسبب التلف أو الانتهاء أو الركود.
- إثبات مخصص انخفاض ومصروف مستقل.
- تحويلات وحدات القياس للصنف.

## 5. الموازنة مقابل الفعلي والتاريخي

تم تنفيذ مقارنة على المستويات التالية:

- يومي.
- شهري.
- سنوي.

وتشمل لكل حساب:

- الموازنة المعتمدة.
- الفعلي من القيود المرحلة فقط.
- الانحراف بالقيمة والنسبة.
- المتوسط التاريخي لعدد السنوات المختار.
- الفرق عن التاريخي.
- تحديد هل الانحراف إيجابي أم سلبي حسب طبيعة الحساب.
- تعليق عربي أو إنجليزي يشرح اتجاه الانحراف.
- تصدير كامل إلى CSV.

## 6. الواجهة التشغيلية

تمت إضافة شاشة ثنائية اللغة باسم:

**الاستيراد والتكلفة والرقابة — Trade, Costing & Controls**

وتشمل:

- إنشاء بيان استيراد مع سبب ضريبة البيان الصفرية.
- سجل بيانات الاستيراد.
- تصدير سجل الواردات.
- عرض قواعد التصدير والاستيراد.
- عرض هيكل تكلفة المنتج النهائي.
- أعمار المخزون.
- مطابقة الجرد المستمر مع الأستاذ.
- مقارنة الموازنة اليومية والشهرية والسنوية.
- التعليقات الآلية.
- تصدير الموازنة مقابل الفعلي والتاريخي.

## 7. حدود الإصدار

RC20 لا يمثل ربطًا إلكترونيًا مع الجمارك أو ZATCA، ولا يرسل الإقرارات. كما لا يُعد اعتمادًا ضريبيًا أو إنتاجيًا نهائيًا قبل اختبار بيانات الشركة والتشغيل الموازي والمراجعة المستقلة.
