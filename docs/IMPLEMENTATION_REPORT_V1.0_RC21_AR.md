# تقرير تنفيذ CORVAX v1.0 RC21
## مرتجعات المبيعات والمشتريات، الإشعارات الدائنة وتسويات VAT

## نطاق التنفيذ

تم بناء دورة أصلية للإشعارات الدائنة بدل الاعتماد على عكس يدوي للقيد أو تغيير حالة الفاتورة. أصبحت كل حركة مرتجع مرتبطة بالفاتورة وسطر الفاتورة والكود الضريبي الأصلي، وتنتقل عبر دورة إعداد واعتماد وترحيل مستقلة.

## المكونات الجديدة

- جداول `credit_notes` و`credit_note_lines` و`credit_note_applications` و`party_credit_balances`.
- ترحيل قاعدة البيانات `e18200000001`.
- 12 مسار API للإشعارات والأرصدة الدائنة والتصدير والمستند المنظم.
- شاشة ثنائية اللغة للمرتجعات والإشعارات الدائنة.
- حساب `424020` لمكاسب فرق تكلفة مرتجع المشتريات.
- حساب `624110` للخسارة غير المستردة من التكلفة الواصلة أو الدفترية.

## الأثر على المبيعات والعملاء

- المرتجع الكامل أو الجزئي يخفض الإيراد وضريبة المخرجات وحساب العميل.
- يطبق الإشعار تلقائيًا على المستند المفتوح الأصلي حتى قيمة الرصيد المتبقي.
- إذا كانت الفاتورة مسددة، يتحول الفرق إلى رصيد دائن للعميل.
- يمكن رد الرصيد نقديًا أو تطبيقه لاحقًا على فاتورة مفتوحة لنفس العميل.
- عودة البضاعة للمخزون تعكس تكلفة المبيعات بالقيمة الدفترية وليس بسعر البيع.

## الأثر على المشتريات والموردين

- الإشعار الوارد من المورد يخفض حساب المورد ويعكس ضريبة المدخلات القابلة للاسترداد.
- مرتجع المخزون يخرج بالقيمة الدفترية الحالية، بما فيها أثر التكلفة الواصلة السابقة.
- الفرق بين القيمة الدفترية وصافي إشعار المورد لا يُخفى داخل المخزون؛ يُعرض كمكسب أو خسارة مرتجع مشتريات.
- يدعم رقم إشعار المورد الخارجي وسجل CSV.

## الأثر الضريبي

- تُحفظ الفاتورة الأصلية في إقرار فترتها.
- يظهر الإشعار الدائن بالسالب في فترة تاريخ الإشعار.
- يُستخدم الكود الضريبي الأصلي للسطر دون إعادة تصنيف يدوي.
- يدعم المرتجع القياسي والصفري والمعفى وخارج النطاق والتصدير والاحتساب العكسي والواردات عبر الإقرار والضريبة غير القابلة للخصم.
- تم إصلاح مرتجعات POS الجزئية واللاحقة لتدخل الإقرار كحركات مستقلة بدل استبعاد كامل عملية البيع.
- الإقرار المعتمد يمنع ترحيل إشعار داخل فترته.

## التصدير والواجهة

- شاشة تشغيل لإنشاء الإشعار من الفواتير المؤهلة والأسطر ذات الكمية المتاحة.
- إرسال واعتماد وترحيل من نفس السجل وفق الصلاحيات.
- عرض الأرصدة الدائنة غير المطبقة.
- تصدير CSV بترميز UTF-8 BOM.
- مستند داخلي منظم للإشعار الدائن للمبيعات برمز 381 وربط الفاتورة الأصلية.

## حدود الإصدار

- الربط الإنتاجي والتوقيع والإرسال إلى ZATCA غير منفذ.
- المرتجعات المباشرة لأوامر البيع والمشتريات غير المرحلة لا تنشئ إشعارًا دائنًا؛ يجب أولًا وجود فاتورة مرحلة.
- إدارة RMA المتقدمة والفحص الفني للبضاعة المرتجعة وإصلاحها وإعادة بيعها تحتاج تعميقًا لاحقًا.
- الإشعار المدين المستقل وتعديلات الأسعار غير المرتبطة بكمية لم تُبنَ كدورة منفصلة بعد.
