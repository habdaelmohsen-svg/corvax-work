# تقرير تنفيذ CORVAX v1.0 RC24
## محرك الزكاة وضريبة الدخل

## نطاق التنفيذ

تم بناء محرك سنوي داخلي لإعداد ومراجعة الزكاة وضريبة دخل الشركات، مرتبط مباشرة بالقيود المرحلة في الأستاذ العام، ويغطي:

- ملف المكلف وأرقام التسجيل.
- تحديد أساس الإقرار: زكاة، ضريبة دخل، أو ملكية مختلطة.
- نسب ملكية السعوديين/الخليجيين وغير السعوديين مع إلزام مجموعها بـ100%.
- استخراج الربح المحاسبي قبل الزكاة والضريبة من القيود المرحلة.
- تعديلات الزيادة والحسم للزكاة وضريبة الدخل مع مرجع الإثبات وحساب المصدر.
- سجل الخسائر الضريبية المرحلة واستخدامها وفق الحد المحدد في ملف المكلف.
- إعداد الوعاء الضريبي وحساب ضريبة الدخل للجزء غير السعودي.
- إعداد وعاء الزكاة وفق نموذج مصادر التمويل ناقص الموجودات القابلة للحسم للجزء السعودي/الخليجي.
- احتساب معدل الزكاة بحسب أيام الفترة المالية مقارنة بأيام السنة الهجرية المحددة.
- أرصدة الدفعات المقدمة والائتمانات.
- تاريخ الاستحقاق الرقابي خلال 120 يومًا من نهاية الفترة.
- دورة مسودة، إرسال، اعتماد مستقل وترحيل.
- قيد استحقاق منفصل للزكاة وضريبة الدخل.
- مطابقة الإقرار مع حسابات الالتزام في الأستاذ العام.
- سداد عبر البنك مع رقم فاتورة سداد ومرجع الدفع.
- تصدير الإقرارات والتعديلات إلى CSV بترميز عربي سليم.
- واجهة عربية RTL وإنجليزية LTR.

## الحسابات المحاسبية

- 218030 — زكاة مستحقة.
- 218040 — ضريبة دخل شركات مستحقة.
- 118020 — دفعات مقدمة للزكاة والضريبة.
- 811010 — مصروف الزكاة والضريبة.
- 811020 — مصروف ضريبة الدخل الحالية.

## ملاحظة مهنية

المحرك لا يدعي أن معادلة واحدة تصلح لكل مكلف. التعديلات النظامية، مصادر التمويل، الحسميات، تغيرات الملكية، المنشأة الدائمة، المعاهدات، الملفات الموحدة والجداول الرسمية تعتمد على وقائع ووثائق المكلف. لذلك حالة الحساب داخل النظام هي `PREPARATION_REVIEW_REQUIRED` حتى تتم المراجعة الضريبية المستقلة.
