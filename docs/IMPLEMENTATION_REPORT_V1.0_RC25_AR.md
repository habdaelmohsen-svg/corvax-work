# تقرير تنفيذ CORVAX v1.0 RC25

## النطاق
استكمال دورة حياة الأصول الثابتة بعد الإضافة والإهلاك، بما يشمل النقل، الانخفاض، المحتفظ به للبيع، البيع، الاستبعاد والشطب.

## المنفذ
- نقل الأصل بين الفروع ومراكز التكلفة والعهدة مع سجل قبل/بعد.
- قيد داخلي لنقل تكلفة الأصل ومجمع الإهلاك والانخفاض بين الأبعاد المحاسبية.
- اختبار انخفاض القيمة وإثبات الخسارة.
- عكس الانخفاض في حدود مجمع الانخفاض والقيمة المسموح بها.
- تصنيف الأصل كمحتفظ به للبيع بالقيمة الأقل من القيمة الدفترية والقيمة العادلة ناقص تكاليف البيع.
- إيقاف الإهلاك أثناء حالة محتفظ به للبيع.
- بيع كامل أو جزئي مع VAT وربح أو خسارة البيع.
- استبعاد أو شطب كامل أو جزئي مع إلغاء التكلفة ومجمع الإهلاك والانخفاض.
- دورة Maker–Checker وسجل مراجعة وتصدير CSV.
- شاشة تشغيل ثنائية اللغة وسجل أصول ومؤشرات لحظية.

## الحسابات المضافة
- 119020 أصول محتفظ بها للبيع.
- 425010 أرباح بيع واستبعاد أصول.
- 426010 مكاسب عكس انخفاض أصول.
- 626010 خسائر بيع واستبعاد وشطب أصول.

## الحدود
لا يشمل RC25 التقييم الخارجي أو محاضر اللجان أو الربط مع سجل أصول ميداني/باركود أو إدارة التأمين على الأصول.
