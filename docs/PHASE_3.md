# Phase 3 — Enterprise & Financial Foundation

Activated in v0.3:
- Company-bound branches.
- Cost centers.
- Fiscal years and accounting periods.
- Period status model: open, soft-closed, future.
- Starter multi-level chart of accounts.
- Protected enterprise APIs using the current access token.
- Arabic/English UI with RTL/LTR maintained across the new screens.

This release is still a development foundation. Data is seeded in memory and will be moved to PostgreSQL with migrations in the next database milestone.
