# الفجوات الخارجية قبل الإنتاج الرسمي

هذه البنود ليست أخطاء برمجية يمكن إغلاقها دون معلومات أو خدمات خارجية:

## ZATCA

- بيانات المنشأة الحقيقية.
- مفاتيح التشفير وOTP/CSID.
- Compliance CSID وProduction CSID.
- اختبار Clearance وReporting الرسمي.
- معالجة ردود وأخطاء الهيئة تحت حساب المنشأة.

## البنوك والمنصات الحكومية

- اتفاقيات API وبيانات الاعتماد.
- قوالب WPS البنكية النهائية.
- حسابات مدد وقوى ومقيم والتأمينات.
- بيئات Sandbox إن وفرتها الجهات.

## اعتماد الشركة

- شجرة حسابات وسياسات نهائية.
- مصفوفة صلاحيات وتفويض مالي.
- أرصدة افتتاحية وترحيل بيانات.
- UAT من المالية والتشغيل والموارد البشرية والجودة.
- Parallel Run ومطابقة شهر كامل.
- موافقة المراجع الداخلي والخارجي.

## الأمن والبنية

- اختبار اختراق مستقل.
- Load/Stress Test على البنية المستهدفة.
- Secret Manager وObject Storage.
- نسخ احتياطي جغرافي وPITR.
- Restore Drill وRPO/RTO موقعان.
