# تقرير الأعمال المتبقية بعد CORVAX RC18

## المرحلة التالية RC19
- مصفوفة Tax Codes مركزية.
- فصل المبيعات والمشتريات القياسية والصفرية والمعفاة وخارج النطاق.
- بناء خانات إقرار VAT السعودي وربط كل حركة بالخانة الصحيحة.
- تسويات ضريبة المدخلات والمخرجات والإشعارات الدائنة والمدينة والفترات السابقة.
- مطابقة إقرار VAT مع حسابات الأستاذ.

## مراحل مالية لاحقة
- RC20: ضريبة الاستقطاع، الانتقائية، الزكاة وضريبة الدخل.
- RC21: نقل الأصل وبيعه واستبعاده وشطبه والانخفاض واختبار المكسب أو الخسارة.
- RC22: Landed Cost والجرد والمخزون الراكد والتالف وNRV وتحويل وحدات القياس.
- RC23: التكاليف الفعلية متعددة المستويات وفروق المواد والأجور والمصاريف الصناعية.

## ملاحظات لم تُغلق في RC18
- إشعارات العملاء والموردين الدائنة والمدينة وربطها تلقائيًا بالأرصدة المفتوحة تحتاج تعميقًا.
- تخصيص العملات المتعددة وفروق الصرف أثناء التسوية يحتاج اختبارًا مستقلًا.
- الأرصدة الافتتاحية القائمة في GL يجب استيراد تفاصيلها قبل اعتبار تقرير الأعمار متطابقًا.
- لا يجوز تشغيل خيار `post_to_gl=false` إلا في ترحيل بيانات مراقب ومطابق مع الأستاذ.
