# تقرير الأعمال المتبقية بعد CORVAX RC19

## أولًا: استكمال ضريبة القيمة المضافة

1. إشعارات دائنة ومدينة مرتبطة بالفاتورة الأصلية وفترتها الضريبية.
2. تعديلات VAT اليدوية مع دورة إعداد ومراجعة واعتماد.
3. الخصم النسبي لضريبة المدخلات والتسوية السنوية.
4. استيراد بيانات البيانات الجمركية ومطابقتها مع ضريبة الواردات.
5. المجموعات الضريبية والإقرار الموحد ومعالجة المعاملات بين أعضاء المجموعة.
6. تحديد دورية الفترات ومواعيد الإقرار والتنبيهات والتصعيدات.
7. سداد الضريبة أو استردادها وتسوية حسابات VAT مع البنك.
8. الربط الرسمي مع ZATCA واختبارات القبول.
9. شاشة إعادة تصنيف المعاملات التاريخية ذات النسبة الصفرية أو غير القياسية.
10. تقارير تدقيق تربط كل خانة بالمستند والقيد الأصلي.

## ثانيًا: الإصدارات الضريبية التالية

- **RC20:** ضريبة الاستقطاع السعودية، تصنيف الدفعات، المستفيدون غير المقيمين والإقرار الشهري.
- **RC21:** الضريبة الانتقائية، تصنيف المنتجات، المستودعات الضريبية والحركات والإقرار.
- **RC22:** الزكاة وضريبة الدخل، تعديلات الوعاء والجداول المساندة والإقرار.

## ثالثًا: الأعمال المالية اللاحقة

- نقل وبيع واستبعاد الأصول واحتساب الربح أو الخسارة.
- التكاليف الإضافية للمشتريات الخارجية Landed Cost.
- الجرد وتسوية الفروقات.
- المخزون الراكد والبطيء والتالف.
- اختبار صافي القيمة القابلة للتحقق NRV.
- تحويلات وحدات القياس المتعددة.
- تعميق التكاليف الفعلية وفروق المواد والأجور والتكاليف الصناعية.

## الأولوية المهنية

لا ينبغي الانتقال إلى الربط الإنتاجي أو تقديم الإقرار من النظام قبل استكمال إشعارات الخصم والإضافة، التعديلات، الخصم النسبي، بيانات الجمارك، والتشغيل الموازي مع إقرار فعلي معتمد.
