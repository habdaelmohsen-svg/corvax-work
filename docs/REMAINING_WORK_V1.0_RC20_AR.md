# CORVAX RC20 — الأعمال المتبقية

## المرحلة التالية حسب الترتيب المالي

### RC21 — ضريبة الاستقطاع

- تصنيف المستفيد غير المقيم.
- نوع الدفعة والنسبة النظامية.
- تاريخ الاستحقاق أو الدفع المحفز للاستقطاع.
- الاتفاقيات الضريبية والمستندات.
- شهادة الاستقطاع.
- الإقرار الشهري والسنوي.
- السداد والمطابقة مع الأستاذ.
- Maker–Checker وسجل مراجعة.

### RC22 — الضريبة الانتقائية

- تصنيف المنتجات الانتقائية.
- الوعاء والمعدل حسب الفئة.
- المستودعات الضريبية.
- الإنتاج والاستيراد والإفراج والاستهلاك.
- الإقرار والمطابقة والسداد.

### RC23 — الزكاة وضريبة الدخل

- تكوين المساهمين ونسب الملكية.
- الوعاء الزكوي وتعديلاته.
- ضريبة الدخل للحصة غير السعودية.
- فروق الربح المحاسبي والضريبي.
- الدفعات المقدمة والإقرار والتسوية.

## وظائف مالية وتشغيلية متبقية

- نقل الأصول بين الفروع ومراكز التكلفة.
- بيع واستبعاد وشطب الأصول واحتساب الربح أو الخسارة.
- الاستثمارات وانخفاضها إن كانت ضمن نطاق الشركة.
- تعميق فروق التكلفة: السعر والكمية والكفاءة والمزيج والطاقة.
- المنتجات المشتركة والثانوية وإعادة التشغيل.
- ربط فعلي ببيانات الجمارك وZATCA والبنوك والأجهزة.

## متطلبات الجاهزية الإنتاجية

- PostgreSQL واختبارات التزامن والأحمال.
- إدارة مفاتيح التشفير عبر Secret Manager.
- اختبار النسخ الاحتياطي والاستعادة في بيئة إنتاج مماثلة.
- أدوات نقل بيانات الشركة والمطابقة.
- UAT لكل إدارة.
- تشغيل موازٍ لدورة مالية كاملة.
- مراجعة ضريبية وIFRS وأمنية مستقلة.
- اختبار اختراق وتعافي من الكوارث.

## الحكم

RC20 يغلق نطاق الواردات والتكلفة الواصلة وتفكيك تكلفة المنتج والجرد المستمر والموازنات تحليليًا وتشغيليًا داخل بيئة الاختبار، لكنه لا يجعل النظام إنتاجيًا نهائيًا قبل إتمام الضرائب المتخصصة ومتطلبات النشر والتشغيل الموازي.
