# الأعمال المتبقية بعد CORVAX RC21

## الأولوية التالية حسب الخطة المالية

### RC22 — ضريبة الاستقطاع السعودية

- ملف المستفيد غير المقيم والإقامة الضريبية.
- تصنيف نوع الدفعة ومعدل الاستقطاع وتاريخ الاستحقاق.
- الضريبة المحجوزة عند السداد أو الاستحقاق حسب السياسة النظامية المعتمدة.
- الإقرار الشهري، شهادة المستفيد، السداد، المطابقة مع الأستاذ، Maker-Checker والتصدير.
- مسار مراجعة منفصل للاتفاقيات الضريبية وعدم تطبيق تخفيض اتفاقية تلقائيًا دون مستندات واعتماد.

## مراحل مالية لاحقة

1. الضريبة الانتقائية ومستودعات ومنتجات الضريبة الانتقائية.
2. الزكاة وضريبة الدخل والتعديلات من الربح المحاسبي إلى الوعاء.
3. نقل وبيع واستبعاد وشطب الأصول ومكاسب وخسائر الاستبعاد.
4. الإشعارات المدينة وتعديلات الأسعار والخصومات اللاحقة غير المرتبطة بمرتجع كمية.
5. إدارة RMA والفحص والجودة للبضاعة المرتجعة.
6. فروق الإنتاج المتقدمة والمنتجات المشتركة والثانوية وإعادة التشغيل.
7. PostgreSQL والأحمال والنسخ الاحتياطي والاستعادة والتعافي من الكوارث.
8. ترحيل البيانات الفعلية، UAT، التشغيل الموازي والربط الخارجي.

## قيود إنتاجية قائمة

RC21 مناسب للتطوير وStaging وUAT. لا يُعتمد كإرسال رسمي إلى ZATCA أو كتشغيل إنتاجي منفرد قبل اكتمال بيانات الاعتماد والاختبارات الخارجية والتشغيل الموازي والمراجعات المستقلة.
