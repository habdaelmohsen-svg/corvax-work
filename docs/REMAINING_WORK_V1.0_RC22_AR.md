# الأعمال المتبقية بعد CORVAX v1.0 RC22

## المرحلة التالية — RC23 الضريبة الانتقائية

- تعريف السلع الانتقائية ونسبها وتواريخ سريانها.
- إدارة المستودعات الضريبية والتراخيص.
- الإنتاج والاستيراد والتحويل والإفراج والاستهلاك والتلف.
- احتساب الوعاء والضريبة حسب الفئة.
- الإقرار والمطابقة مع المخزون والأستاذ العام.
- الاعتمادات والتصدير وسجل المراجعة.

## RC24 الزكاة وضريبة الدخل

- ملف الملكية السعودية وغير السعودية.
- الوعاء الزكوي والتعديلات والحسومات.
- الربح المعدل ضريبيًا وضريبة الدخل.
- الاستقطاعات والدفعات المقدمة والتسويات.
- الإقرار والمطابقة مع القوائم والأستاذ.

## RC25 دورة حياة الأصول

- نقل الأصل بين الفرع والقسم ومركز التكلفة.
- البيع والاستبعاد والشطب والتقاعد.
- مكاسب وخسائر الاستبعاد والضريبة.
- انخفاض القيمة والأصول المحتفظ بها للبيع.

## تعميق مالي وتشغيلي لاحق

- إشعارات مدينة مستقلة وتعديلات الأسعار غير المرتبطة بكمية.
- العملات الأجنبية في ضريبة الاستقطاع وفروق الصرف المحققة.
- أتمتة المطالبة برد الضريبة وفق المعاهدات بعد توفير التكامل الرسمي.
- PostgreSQL والأحمال والتزامن والنسخ الاحتياطي والاستعادة.
- ترحيل البيانات الحقيقية والتشغيل الموازي وUAT.
- الربط الرسمي مع ZATCA والبنوك والمنصات الحكومية والأجهزة.
