# الأعمال المتبقية بعد CORVAX RC23

## المرحلة المالية التالية

### RC24 — الزكاة وضريبة الدخل

- ملف ملكية الشركاء السعوديين وغير السعوديين.
- جسر الربح المحاسبي إلى الربح المعدل ضريبيًا وزكويًا.
- الإضافات والحسومات والوعاء الزكوي.
- الأصول والحسومات الزكوية وفق التصنيف المعتمد.
- ضريبة الدخل ونسبة الملكية الخاضعة.
- الخسائر المرحلة والدفعات المقدمة والتسويات.
- إعداد ومراجعة واعتماد الإقرار.
- مطابقة المخصصات والدفعات مع الأستاذ العام.
- تصدير أوراق العمل والإقرار الداخلي.

## الضريبة الانتقائية المتبقية للإنتاج الرسمي

- ربط الجمارك والهيئة بالاعتمادات الرسمية.
- مطابقة البيانات الفعلية للبيانات الجمركية.
- إدارة الأختام الضريبية بالأرقام التسلسلية.
- احتساب تعديلات الأسعار والتصنيف بأثر رجعي عند الحاجة.
- إدارة المخالفات والاعتراضات والتعديلات الرسمية.
- اختبار المنتجات الفعلية والتعرفة والعبوات ووحدات القياس.

## مراحل لاحقة

- نقل وبيع واستبعاد وشطب الأصول الثابتة.
- تعميق فروق التكاليف الفعلية والمعيارية.
- PostgreSQL والأحمال والتزامن.
- أدوات ترحيل البيانات والأرصدة الافتتاحية.
- UAT لكل إدارة والتشغيل الموازي.
- الربط الخارجي والاختبارات الأمنية المستقلة.
