# نطاق الامتثال السعودي في CORVAX v0.16

## ما تم تنفيذه

### نهاية الخدمة
- محرك قواعد مؤرخة بدل معادلة ثابتة غير قابلة للتتبع.
- الاحتساب الحالي يغطي القاعدة العامة للسنوات الخمس الأولى وما بعدها، ونسب الاستقالة حسب مدة الخدمة.
- يحتفظ النظام بالمصدر وتاريخ السريان والمعاملات المستخدمة.

### الفوترة الإلكترونية
- توليد XML محلي كأساس تقني.
- UUID وعداد وسلسلة hash وQR TLV.
- تحقق محلي من البيانات والمجاميع.
- منع الادعاء بأن الفاتورة cleared/reported لدى ZATCA.

### ضريبة القيمة المضافة
- لقطة إقرار من الحركات المرحلة.
- فصل ضريبة المخرجات والمدخلات وصافي المستحق.

## ما لم يتم تنفيذه أو اعتماده

- CSID onboarding وتجديد الشهادة.
- Cryptographic stamp مطابق ومعتمد.
- Clearance لفواتير B2B وreporting للفواتير المبسطة.
- معالجة ردود API والأخطاء وإعادة الإرسال.
- اختبار conformance وsandbox ثم production.
- التحقق من جميع business rules وUBL schematron الرسمية.
- إقرار ضريبي إلكتروني مقدم فعليًا للهيئة.

## ضابط الاستخدام

كل حساب قانوني أو ضريبي في النظام يجب أن يمر بمراجعة المختص قبل الإنتاج، مع تحديث جدول القواعد عند تغير الأنظمة أو التفسيرات الرسمية. لا يُعد وجود شاشة أو XML محلي إثباتًا للامتثال أو شهادة اعتماد.
