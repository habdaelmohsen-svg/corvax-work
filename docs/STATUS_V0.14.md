# CORVAX Business Platform v0.14 — تقرير حالة التنفيذ

## النتيجة الحالية

- تغطية نطاق العرض الوظيفي: **88%**.
- الجاهزية العامة للاستخدام الإنتاجي: **47%**.
- جاهزية النواة المالية والدفاتر الفرعية: **72%**.
- جاهزية العمليات الصناعية والمخزون: **58%**.

هذه النسب منفصلة عمدًا: وجود شاشة أو API لا يعني اكتمال الأمن والامتثال والاختبارات اللازمة للإنتاج.

## المنجز فعليًا

1. النواة متعددة الشركات والفروع ومراكز التكلفة.
2. المستخدمون والأدوار والصلاحيات وسجل التدقيق.
3. دفتر الأستاذ ودورة القيد والقوائم المالية والتدفقات النقدية.
4. العملاء والموردون والبنوك والقبض والصرف.
5. التسويات البنكية والموازنة والرقابة.
6. المخزون والمشتريات والمطابقة الثلاثية.
7. التصنيع والتكاليف وOEE والجودة.
8. عضويات النادي والإيراد المقدم والاعتراف الشهري.
9. محرك عقود الإيجار الأولي وفق IFRS 16.
10. الأصول الثابتة والإهلاك الأولي وفق IAS 16.
11. الرواتب الأساسية والترحيل والصرف البنكي.
12. POS المطاعم والوصفات وتكلفة الطعام وتسويات منصات التوصيل.
13. واجهة عربية/إنجليزية متصلة بالمحركات الجديدة.
14. Docker وRender وPostgreSQL migrations.

## ما يزال متبقيًا قبل التشغيل الرسمي

### أمن وتشغيل
- MFA وسياسة كلمات المرور والجلسات والأجهزة.
- تشفير حقول حساسة وإدارة أسرار احترافية.
- نسخ احتياطي آلي واختبار استعادة ومراقبة وتنبيهات.
- اختبارات اختراق وضغط وتدقيق أمن الكود.

### مالية ومعايير
- IFRS 9 وخسائر الائتمان المتوقعة.
- العملات وإعادة التقييم والفروق.
- توحيد القوائم والإلغاءات بين الشركات.
- الإقفالات الشهرية والسنوية المتقدمة.
- التغيرات المحاسبية والإفصاحات الكاملة وفق IFRS 18.
- إدارة الزكاة والضرائب والضريبة المؤجلة عند انطباقها.

### السعودية
- ZATCA Phase 2 XML والتوقيع والتكامل.
- جدول قواعد موارد بشرية سعودي بإصدارات وتواريخ سريان.
- WPS file formats النهائية والتكاملات المتاحة.
- قوى ومدد ومقيم والتأمينات وفق واجهات الربط الرسمية المتاحة.

### الموارد البشرية
- العقود والورديات والحضور والإجازات والإضافي والجزاءات.
- السلف والقروض والتذاكر والتأمين الطبي.
- نهاية الخدمة وIAS 19 والتقييم الاكتواري.

### التشغيل
- مرتجعات المبيعات والمشتريات وعمليات الجرد والتحويل المتقدمة.
- صيانة المصنع وقطع الغيار والصيانة الوقائية.
- مطابخ وطاولات وKDS وورديات وإقفال كاشير كامل.
- تعديلات عقود العضوية والإيقاف والتجميد والإلغاء والاسترداد.
- تعديلات وإعادة قياس وإنهاء عقود الإيجار.
- بيع وشطب وتحويل وانخفاض قيمة الأصول.

### المراجعة والجودة
- خطة مراجعة مبنية على المخاطر وأوراق عمل وعينات وPBC.
- مكتبة سياسات ISO وإدارة النسخ وعدم المطابقة والإجراءات التصحيحية.
- صلاحية دخول المراجع الخارجي محددة زمنيًا.

## القرار الفني للمرحلة التالية

الأولوية الصحيحة ليست زيادة عدد الشاشات، بل:

1. ZATCA والضرائب السعودية.
2. HR والحضور والإجازات ونهاية الخدمة.
3. الأمن والنسخ الاحتياطي والمراقبة.
4. الإقفالات والتوحيد والعملات وIFRS 9.
5. اختبارات End-to-End وضغط وأمن وقبول مستخدمين.
