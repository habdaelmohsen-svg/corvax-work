# تقرير حالة CORVAX Business Platform v0.16

## الملخص التنفيذي

الإصدار v0.16 يضيف طبقة رقابية حقيقية فوق المحركات المالية والتشغيلية السابقة. أهم ما تغير هو أن الأمن، الحضور، الإجازات، نهاية الخدمة، الإقفال المالي، الامتثال المحلي، والنسخ الاحتياطي أصبحت معاملات محفوظة في قاعدة البيانات مع صلاحيات وسجل تدقيق، وليست بطاقات عرض فقط.

### التقدير الحالي

| المقياس | النسبة التقديرية |
|---|---:|
| تغطية العرض الوظيفي | 91% |
| الجاهزية الإنتاجية الإجمالية | 57% |
| جاهزية النواة المالية | 77% |
| جاهزية الموارد البشرية التشغيلية | 48% |
| جاهزية الامتثال السعودي | 35% |

> لا تعني نسبة العرض أن النظام جاهز قانونيًا أو إنتاجيًا. الربط الرسمي مع الجهات، اختبارات الأمان والضغط، وخطة الاستعادة ما زالت مطلوبة.

## المنجز في v0.16

### 1. أمن الحسابات
- قفل حساب بعد عدد محاولات قابل للضبط.
- جلسات مسجلة وإلغاء جلسات.
- MFA باستخدام TOTP.
- تغيير كلمة المرور مع تاريخ كلمات سابقة.
- فتح الحساب وإعادة تعيين كلمة المرور وتعطيل المستخدم إداريًا.
- فحص إعدادات الإنتاج ومنع secret ضعيف أو demo seed أو origins مفتوحة.

### 2. الحضور والإجازات
- تعريف ورديات وإسنادها للموظفين.
- منع الحضور دون وردية فعالة.
- ربط الفرع بإحداثيات ونطاق geofence.
- Clock-in/Clock-out مع التأخير والعمل الإضافي.
- إدخال يدوي بسبب وسجل تدقيق.
- Finalize day لإنشاء الغياب أو ربط الإجازة المعتمدة.
- أنواع إجازات وطلب واعتماد ورصيد.

### 3. نهاية الخدمة
- قاعدة قانونية مؤرخة وقابلة للإصدار.
- حساب نصف شهر للسنوات الخمس الأولى وشهر لما بعدها ضمن القاعدة الحالية.
- نسب الاستحقاق في الاستقالة حسب مدة الخدمة.
- حفظ تفاصيل الحساب والقاعدة القانونية المستخدمة.
- اعتماد Maker-Checker وقيد محاسبي للمصروف والالتزام.

### 4. الإقفال المالي
اختبارات الإقفال الحالية:
1. القيود غير المرحلة.
2. كشوف البنك غير المسواة.
3. تسويات POS المعلقة.
4. مسير الرواتب غير المكتمل.
5. المخزون السالب.
6. جداول الاعتراف بالإيراد المستحقة.
7. جداول الإيجار المستحقة.
8. توازن ميزان المراجعة.
9. ملاحظات الجودة المتأخرة كتحذير غير مانع.

الإقفال يتطلب مستخدمًا مختلفًا عن طالب الإقفال، ويمكن إعادة الفتح بسبب إلزامي مع سجل تدقيق.

### 5. الفوترة والضريبة
- XML محلي من فواتير البيع أو POS.
- UUID وICV وPIH hash chain وQR TLV.
- فحص محلي للضريبة والمجاميع.
- لقطة إقرار VAT للفترة.
- حالة صريحة: `PENDING_CSID_AND_SANDBOX_CERTIFICATION`.

### 6. النسخ الاحتياطي
- SQLite online backup.
- PostgreSQL pg_dump عند توفر الأداة.
- Manifest وSHA-256 وCRC.
- اختبار سلامة SQLite.
- سجل نسخة وحالة تحقق.

## ما بقي قبل التشغيل الرسمي

### مانع تشغيل رئيسي
- ZATCA onboarding وCSID وواجهات clearance/reporting واختبارات sandbox والإنتاج.
- إدارة شهادات التوقيع والتجديد والإلغاء.
- حماية أسرار المؤسسة عبر secret manager.
- تشفير الحقول الحساسة at rest.
- اختبارات اختراق وضغط وتدقيق كود مستقل.
- نسخ احتياطية مجدولة خارج الخادم واختبار restore فعلي دوري.
- High availability وmonitoring وalerts.

### الموارد البشرية
- العقود وفترات التجربة والتجديد.
- قواعد حضور متعددة للورديات الليلية والمرنة والراحة.
- العطلات الرسمية والتقويمات.
- خصم التأخير والغياب وإضافة الإضافي إلى مسير الرواتب آليًا.
- السلف والقروض والجزاءات والتذاكر والتأمين الطبي.
- ملف WPS لكل بنك وربط متطلبات مدد.
- IAS 19 وتقييم اكتواري.

### المالية
- العملات وإعادة التقييم.
- IFRS 9 وECL.
- التوحيد والحذف بين الشركات.
- إقفال سنوي وفتح أرصدة.
- إفصاحات IFRS 18 الكاملة.
- إعداد ضريبي وزكوي متكامل ومعتمد.

### التشغيل
- MRP وRouting متعدد المراحل وWIP متقدم.
- صيانة وقائية وتصحيحية وقطع غيار.
- POS offline وإقفال الكاشير الكامل.
- دورة النادي الكاملة للتجميد والإلغاء والجلسات والعمولات.

### الإطلاق
- ترحيل بيانات حقيقي ومطابقة أرصدة افتتاحية.
- UAT لكل إدارة.
- تدريب ودليل إجراءات.
- Pilot على شركة/فرع محدود قبل التعميم.

## قرار الاستخدام

- مناسب الآن: العرض، الاختبار، مراجعة الإجراءات، وتجربة Pilot ببيانات غير حساسة أو منسوخة بعد إخفائها.
- غير مناسب الآن: الاعتماد الرسمي كحل مالي/ضريبي وحيد أو تخزين بيانات شديدة الحساسية دون استكمال ضوابط الإنتاج.
