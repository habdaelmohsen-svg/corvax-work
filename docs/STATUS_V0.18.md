# CORVAX Business Platform v0.18 — تقرير حالة التنفيذ

## المنجز الجديد

- سجل عملات وأسعار صرف مؤرخة لكل شركة.
- أرصدة حسابات بالعملة الأجنبية مع القيمة الدفترية بالعملة الوظيفية.
- إعادة تقييم وفق أساس IAS 21 مع قيد آلي متوازن وربح أو خسارة غير محققة.
- تحديث القيمة الدفترية وسعر الإقفال وسجل المراجعة.
- مجموعات توحيد متعددة الشركات.
- تجميع أرصدة الشركات من القيود المرحلة حتى تاريخ التقرير.
- قيود استبعاد يدوية مع منع حفظ تجميع غير متوازن.
- تقرير تجميع تفصيلي حسب الحساب.
- شاشة عربية/إنجليزية للعملات والتوحيد.
- Migration جديدة وترقية الإصدار إلى 0.18.0.

## الحدود الحالية

- الترجمة الكاملة لقوائم المنشآت الأجنبية وفق IAS 21 لم تكتمل بعد.
- حقوق الأقلية والاستحواذ والشهرة واختبار انخفاضها غير مكتملة.
- المطابقة الآلية للأرصدة والمعاملات بين الشركات تحتاج معرفات طرف مقابل موحدة.
- أسعار الصرف تُدخل يدويًا أو عبر API داخلي؛ لا يوجد ربط مباشر بمصدر خارجي حتى الآن.

## التقييم

- تغطية العرض الوظيفي: 93%.
- جاهزية النواة المالية: 81%.
- الجاهزية الإنتاجية الإجمالية: 61%.
- التوحيد والعملات: 55%.
