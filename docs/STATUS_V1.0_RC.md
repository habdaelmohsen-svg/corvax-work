# CORVAX v1.0 RC1 — تقرير الحالة التنفيذي

## الحكم المهني

الإصدار الحالي هو مرشح إصدار للنواة المؤسسية. لم تعد المراجعة والحوكمة والإدارة الإلكترونية والتسويق مجرد لوحات ثابتة؛ أصبحت لها جداول وواجهات API وصلاحيات وسجل تدقيق واختبارات فعلية.

## المنجز في RC1

### المراجعة والحوكمة

- سجل مخاطر بدرجات الاحتمال والأثر والمخاطر الجوهرية والمتبقية.
- مكتبة ضوابط مرتبطة بالمخاطر مع حالة التصميم والفعالية التشغيلية.
- مهام مراجعة داخلية وخارجية وخطط وتواريخ ونطاق.
- ملاحظات مراجعة، خطورة، سبب جذري، توصية ومسؤول وتاريخ استحقاق.
- إجراءات تصحيحية ونسب إنجاز ومراجع أدلة.
- وثائق وسياسات مضبوطة بالإصدار والتاريخ والمراجعة وMaker-Checker.

### الإدارة الإلكترونية وITSM

- سجل أصول تقنية وحالة وأهمية وضمان وتخصيص.
- تذاكر دعم بأولوية وموعد SLA وتعيين وبدء وحل.
- احتساب التذاكر المتأخرة ونسبة SLA.
- سجل تدقيق لكل تغيير.

### CRM والتسويق

- حملات تسويقية وميزانية وقناة ومدة.
- عملاء محتملون ومصدر وقيمة تقديرية.
- تحويل العميل المحتمل إلى فرصة.
- مراحل الفرصة واحتمال الإغلاق والقيمة المرجحة والفوز والخسارة.
- لوحة Pipeline مستخرجة من قاعدة البيانات.

### الجاهزية التشغيلية

- إصدار موحد `1.0.0-rc1`.
- Migration head: `e10000000001`.
- 112 جدولًا في قاعدة جديدة تشمل Alembic.
- فحوص Liveness وReadiness.
- رؤوس أمان وRequest ID.
- Docker بمستخدم غير root وHealthcheck.
- Docker Compose مع PostgreSQL.
- أداة تحقق واستعادة للنسخ.
- تحديث الواجهة المجمعة داخل Backend.

## الموجود من الإصدارات السابقة

كل المحركات السابقة محفوظة: المالية، القوائم، الإقفال، الأصول، المصروفات المقدمة، الاستحقاقات، العملات، IFRS 9/15/16، التوحيد، المخزون، المشتريات، المبيعات، التصنيع، التكاليف، الصيانة، الجودة، النادي، المطاعم، الموارد البشرية، الرواتب، الحضور، نهاية الخدمة والامتثال المحلي الأساسي.

## ما يمنع تسمية النسخة Production Final

1. ZATCA الرسمية تحتاج CSID واعتماد Sandbox/Production.
2. تكاملات البنوك والجهات الحكومية تحتاج بيانات اعتماد وعقود وصول.
3. يلزم اختبار اختراق وضغط بواسطة جهة مستقلة.
4. يلزم Restore Drill على خادم منفصل في بيئة العميل.
5. يلزم UAT موقع وParallel Run وإقفال شهر وسنة على بيانات حقيقية.
6. يلزم اعتماد السياسات المحاسبية والضريبية والموارد البشرية من أصحاب الصلاحية.
7. التصميم البصري النهائي ما زال مرحلة مستقلة بعد تثبيت الوظائف.

## التقييم

- اكتمال النواة الوظيفية المتفق عليها: مرتفع.
- جودة الربط المحاسبي الأساسي: متقدمة.
- جاهزية النشر التجريبي Pilot: نعم.
- جاهزية استبدال النظام الرسمي فورًا: لا، حتى إغلاق البنود الخارجية أعلاه.
