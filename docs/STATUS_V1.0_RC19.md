# CORVAX v1.0 RC19 — VAT Return Classification & Tax Code Matrix

## Status

Release stage: **Release Candidate — Staging / UAT only**

## Completed

- Company-specific tax-code matrix.
- Sales classifications: standard, zero-rated domestic, exports, exempt and out of scope.
- Purchase classifications: standard, zero-rated, exempt, out of scope, imports paid at customs, reverse charge and non-deductible VAT.
- Explicit tax code on AR, AP and POS transaction lines.
- Correct document-total and journal behavior for reverse-charge and non-deductible VAT.
- Classified VAT return snapshot.
- Output/input VAT reconciliation to the general ledger.
- Maker-checker approval and immutable approved snapshots.
- Bilingual VAT control interface.

## Not completed

- ZATCA electronic filing or tax-portal integration.
- Credit/debit note VAT adjustments.
- Partial exemption and annual input-tax adjustment.
- VAT groups and consolidated returns.
- Customs declaration ingestion.
- VAT payment and refund settlement workflow.
- Withholding tax, excise tax, zakat and income tax.
