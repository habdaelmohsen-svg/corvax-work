# CORVAX v1.0 RC2 — تقرير الحالة التنفيذي

## الحكم المهني

أصبح النظام يحتوي على بوابة تأكيد مالي ورقابي مستقلة تمنع الاعتماد عند وجود موانع جوهرية. هذه البوابة لا تستبدل المراجع الخارجي ولا تمنح شهادة امتثال، لكنها تفرض داخل النظام انضباطًا قريبًا من منهجيات المراجعة المؤسسية الكبيرة: أهمية نسبية، اختبارات مانعة، فصل مهام، إقرارات مكتوبة، وسجل مراجعة.

## الجديد في RC2

- تحديد الأهمية النسبية العامة، أهمية الأداء، وحد الأخطاء التافهة لكل فترة.
- فحوص الإقفال المالي والقوائم والمركز المالي.
- فحوص المخاطر والضوابط وملاحظات المراجعة والإجراءات التصحيحية.
- فحوص المعاملات بين الشركات، العملات الأجنبية، IFRS 9، والسياسات.
- تحذير مستقل للفواتير الإلكترونية التي لم تُبلغ أو تعتمد خارجيًا.
- استنتاج آلي: READY أو CONDITIONAL أو NOT_READY.
- منع تقديم الملف عند وجود فحص مانع فاشل.
- تسلسل شهادات: Financial Controller ثم CFO، مع Internal Audit لإقفال السنة.
- منع مُعد الملف من اعتماده.
- منع مستخدم واحد من إصدار أكثر من شهادة.
- صلاحيات مستقلة: assurance.read / assurance.review / assurance.approve.
- شاشة عربية وإنجليزية داخل الواجهة لعرض النتيجة والفحوص والأهمية النسبية.

## ما بقي خارج الكود

- ZATCA CSID والاختبارات الرسمية.
- بيانات اعتماد البنوك والجهات الحكومية.
- اختبار اختراق وضغط مستقل.
- UAT وParallel Run وترحيل البيانات الفعلية.
- اعتماد السياسات المحاسبية والضريبية والموارد البشرية.
- إعادة التصميم البصري الشاملة بعد تثبيت المحركات.

## قرار الاستخدام

- مناسب لـ Staging وPilot وUAT.
- مناسب لإقفال تجريبي ومراجعة داخلية تجريبية.
- غير مناسب بعد لإلغاء النظام الرسمي أو تقديم إقرار ضريبي رسمي دون إغلاق البنود الخارجية.
