# CORVAX v1.0 RC8 — Financial Close Workbench Status

## الحالة

**Release Candidate — حزمة إقفال مالي مؤسسية قابلة للاختبار الداخلي، وليست قوائم مدققة أو تقييمًا مستقلاً أو توقيعًا إلكترونيًا مؤهلًا.**

## ما أضيف في RC8

### IFRS 3 وتخصيص سعر الشراء

- ربط الاستحواذ بمجموعة توحيد وبشركتين عضوين فيها.
- منع تطابق الشركة المستحوِذة والمستحوَذ عليها.
- تحديد نسبة الملكية وطريقة قياس حقوق غير المسيطرين: القيمة العادلة أو الحصة النسبية.
- إدخال المقابل النقدي والأسهم والمقابل المحتمل والحصة المحتفظ بها سابقًا.
- تعريف عناصر PPA كأصول أو التزامات أو التزامات محتملة، مع القيم الدفترية والعادلة والأسس الضريبية والأدلة.
- احتساب تعديل القيمة العادلة وأثر الضريبة المؤجلة وصافي الأصول القابلة للتحديد.
- احتساب الشهرة أو ربح الشراء بسعر منخفض.
- فصل الإعداد والمراجعة والاعتماد النهائي.
- إنشاء ورقة توحيد متوازنة آليًا بعد الاعتماد.

### منصة أوراق التوحيد

- أوراق تعديل يدوية مرتبطة بمجموعة التوحيد والفترة والمرجع.
- بنود مدين ودائن مع نوع التعديل وكود الحساب ومرجع المصدر.
- رفض السطور ذات الطرفين الصفريين أو المدين والدائن معًا.
- منع المراجعة عند وجود فرق أو نقص في مراجع المصدر.
- اعتماد مستقل بثلاث مراحل وسجل تدقيق.

### Lead Schedules والأدلة

- تحديد نطاق الحسابات والفترة ورصيد دفتر الأستاذ المرحّل الفعلي.
- بنود تفصيلية للتسوية، المالك، الاستحقاق، العمر والحالة.
- احتساب إجمالي الورقة والفرق مع دفتر الأستاذ.
- حالة مانعة `BLOCKED_UNRECONCILED` عند وجود فرق.
- منع المراجعة دون دليل أو عند عدم التسوية.
- رفع PDF وCSV وXLSX وPNG وJPEG بحد أقصى 10 MB.
- SHA-256 لكل ملف ومنع الدليل المكرر.
- تخزين مسار نسبي قابل للنقل داخل مجلد بيانات النظام.
- اعتماد نهائي محكوم بالمُعد والمراجع والمعتمد؛ الحالة `APPROVED_AND_SIGNED` تعني توقيعًا رقابيًا داخليًا، وليس توقيعًا إلكترونيًا مؤهلًا قانونيًا.

### تخفيض نطاق الإيجار جزئيًا

- معالجة عقد إيجار نشط فقط مع جداول مستقبلية غير مرحلة.
- احتساب القيمة الدفترية للالتزام وحق الاستخدام في تاريخ النفاذ.
- احتساب الإلغاء النسبي والربح أو الخسارة.
- قيد محاسبي مرحّل آليًا بعد اعتماد مستخدم مستقل.
- تخفيض الجداول المستقبلية ومبلغ الدفعة بنسبة النطاق المتبقي.
- ربط العملية بالقيد وسجل المراجعة.

### الواجهة والرقابة

- بطاقات جديدة في قسم المالية المؤسسية للاستحواذ، Lead Schedules، أوراق التوحيد وتخفيض الإيجار.
- لوحة بيانات من API فعلي وليست أرقامًا ثابتة.
- سجل الموديولات وHealth وRelease API محدثة إلى RC8.
- العربية RTL والشريط على اليمين، والإنجليزية LTR والشريط على اليسار.

## الحكم الصارم

RC8 أغلق أهم فجوات IFRS 3 الأساسية، أوراق التوحيد، Lead Schedules والأدلة، وتخفيض نطاق الإيجار. لكنه لا يجعل المالية 100%.

المتبقي المالي الأهم:

- الاستحواذ المرحلي المعقد وإعادة قياس الحصص السابقة بقيود دفترية كاملة.
- المقابل المحتمل بعد تاريخ الاستحواذ وتكاليف الصفقة وترتيبات التعويض المنفصلة.
- نموذج تقييم مستقل للقيم العادلة وربط تقارير المقيمين.
- IAS 29 والتخلص من العمليات الأجنبية وإعادة تدوير CTA.
- ضريبة مؤجلة متعددة الاختصاصات، المقاصة القانونية والمواقف الضريبية غير المؤكدة.
- منصة توحيد نهائية تجمع أرصدة كل الشركات وتطبق كل أوراق التعديل والاستبعاد وتنتج TB موحدًا آليًا.
- قوالب Lead Schedules خاصة بالشركة، توقيعات قانونية مؤهلة وحفظ مستندات خارجي محكوم.
- إقفال موازٍ على بيانات حقيقية ومراجعة مراجع خارجي ومستشار ضريبي.

## التقييم بعد RC8

- المالية الداخلية: **نحو 95–96%** ضمن النطاق الداخلي القابل للتنفيذ دون جهات خارجية.
- النظام ككل: **نحو 89%**؛ لأن التصنيع المتقدم وHR والمطاعم والنادي والأمن التشغيلي لا تزال تحتاج حزمًا رئيسية.

هذه نسب تقييم هندسي ورقابي داخلي، وليست شهادة امتثال أو اعتمادًا خارجيًا.
