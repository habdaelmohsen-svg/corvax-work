# CORVAX Business Platform v0.14 — تقرير الاختبارات

## اختبارات نجحت

- تشغيل التطبيق وتسجيل الدخول.
- ترحيل قاعدة البيانات من الصفر حتى v0.14.
- ترقية قاعدة v0.12 إلى v0.14.
- إنشاء البيانات التجريبية والصلاحيات والحسابات الجديدة.
- التسوية البنكية حتى حالة RECONCILED.
- رقابة الموازنة والفعلي.
- أمر شراء واعتماد واستلام ومطابقة ثلاثية.
- صرف خامات وإتمام إنتاج وحساب التكلفة وOEE.
- فحص جودة وإنشاء NCR وتحديث الإجراء التصحيحي.
- بيع عضوية وجدول IFRS 15 والاعتراف الشهري.
- إنشاء عقد IFRS 16 وترحيل أول جدول شهري.
- رسملة أصل ثابت وتشغيل إهلاك سياسة 15 يومًا.
- إنشاء مسير رواتب وترحيل الاستحقاق وصرف صافي الرواتب.
- بيع مطعم من منصة توصيل واستهلاك الوصفة وتسوية العمولة.
- توازن ميزان المراجعة والمركز المالي بعد كل القيود الآلية.
- بناء React وTypeScript للإنتاج.
- تقديم الواجهة والـAPI من خدمة واحدة.
