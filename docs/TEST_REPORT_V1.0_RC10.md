# تقرير اختبارات CORVAX v1.0 RC10

## اختبارات الحزمة الجديدة

نجح السيناريو المتكامل التالي:

1. إنشاء مسار من عمليتين وربطه بمنتج تام وBOM.
2. رفض اعتماد مُعد المسار لمساره.
3. اعتماد المسار بواسطة مستخدم مستقل.
4. تشغيل MRP لطلب 7,000 وحدة مع مخزون أمان.
5. انفجار BOM إلى المواد الخام والتعبئة وإصدار توصيات MAKE/BUY.
6. رفض اعتماد مُعد MRP لخطته واعتمادها بواسطة مستخدم مستقل.
7. إنشاء أمر إنتاج وصرف خاماته.
8. تحويل المسار إلى عمليات أمر إنتاج.
9. بدء وإتمام العمليات بالتسلسل مع تسجيل الكميات الجيدة والمرفوضة.
10. تسجيل هالك غير طبيعي بقيمة 20.
11. إتمام الإنتاج وتسجيل المنتج التام.
12. إعداد إقفال تكلفة ببصمة SHA-256.
13. رفض المراجعة الذاتية والاعتماد غير المستقل.
14. مراجعة واعتماد الإقفال بثلاثة مستخدمين.
15. إنشاء قيد انحرافات متوازن ومرحّل.
16. التحقق من لوحة التصنيع المتقدمة والحسابات الجديدة.
