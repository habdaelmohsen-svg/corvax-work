# تقرير اختبارات CORVAX RC19

## 1. اختبار السيناريو الضريبي الشامل

تم إنشاء وترحيل معاملات تغطي الأكواد التالية:

- S15: مبيعات قياسية.
- S0: مبيعات محلية صفرية.
- SEX: صادرات صفرية.
- SE: مبيعات معفاة.
- SOOS: مبيعات خارج النطاق.
- P15: مشتريات محلية قياسية.
- P0: مشتريات صفرية.
- PE: مشتريات معفاة.
- PIMP15: واردات مسددة ضريبتها في الجمارك.
- PRC15: مشتريات خاضعة للاحتساب العكسي.
- PND15: ضريبة مدخلات غير قابلة للخصم.

### نتائج السيناريو

| المؤشر | النتيجة |
|---|---:|
| أساس المبيعات القياسية | 1,000 ريال |
| ضريبة المبيعات القياسية | 150 ريال |
| ضريبة مخرجات الاحتساب العكسي | 75 ريال |
| إجمالي ضريبة المخرجات | 225 ريال |
| ضريبة المدخلات القابلة للاسترداد | 315 ريال |
| صافي الضريبة | 90 ريال قابلة للاسترداد |
| فرق ضريبة المخرجات مع الأستاذ | صفر |
| فرق ضريبة المدخلات مع الأستاذ | صفر |

تم التحقق كذلك من أن ضريبة المدخلات غير القابلة للخصم، وقيمتها 60 ريالًا في السيناريو، حُمّلت على المصروف ولم تدخل ضمن الضريبة القابلة للاسترداد.
