# تقرير اختبارات CORVAX RC24

## الاختبار الوظيفي

نجحت دورة كاملة تضمنت:

- ربحًا محاسبيًا قبل الزكاة والضريبة بقيمة 700,000 ريال.
- تعديلات ضريبة دخل: إضافة 50,000 وحسم 10,000 ريال.
- ملكية غير سعودية 40%.
- خسائر مرحلة 100,000 ريال وحد استخدام 25% من الأساس قبل الخسائر.
- استخدام خسارة 74,000 ريال، ووعاء ضريبة دخل 222,000 ريال، وضريبة إجمالية 44,400 ريال.
- ائتمان ضريبة دخل 4,000 ريال، وصافي ضريبة دخل 40,400 ريال.
- تعديلات زكوية: إضافة 100,000 وحسم 20,000 ريال.
- وعاء زكوي إجمالي 80,000 ريال، ونصيب ملكية سعودية/خليجية 60% بقيمة 48,000 ريال.
- تطبيق معدل زكاة مُرحّل حسب 365 يومًا مقارنة بـ354 يومًا هجريًا.
- رفض اعتماد المُعد لإقراره.
- ترحيل الاستحقاق، المطابقة مع الأستاذ، السداد وإغلاق الالتزامات.
- بقاء الخسائر المتاحة بعد الاستخدام بقيمة 26,000 ريال.
- توازن القيود وعدم وجود مخالفات مفاتيح خارجية.
- نجاح تصدير CSV العربي.

## تصحيح تم أثناء الاختبار

اكتُشف أن التعديل المضاف في الطلب الحالي كان يُحفظ في قاعدة البيانات لكن مجموعة التعديلات المحملة مسبقًا لا تراه أثناء نفس إعادة الحساب. تم ربط التعديل مباشرة بعلاقة الإقرار قبل إعادة الحساب، ثم أُعيد الاختبار بنجاح.

كما اكتُشف رأس ترحيل قديم داخل سجل المديولات، وتم تحديثه إلى `e18500000001` وإعادة الاختبارات.
