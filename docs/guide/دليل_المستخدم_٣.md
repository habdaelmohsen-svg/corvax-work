# دليل استخدام CORVAX — الدفعة ٣

## الضرائب والزكاة (٥ أقسام)

> كل رمز ضريبي وكل نسبة هنا مأخوذة من النظام مباشرة.

---

# أولًا: الأساس — المصفوفة الضريبية

قبل أي قسم، افهم هذه المصفوفة. **النظام يستخدمها في كل فاتورة**، وعليها يتوقف إقرارك.

## رموز المشتريات

| الرمز | الوصف | النسبة | تُخصم؟ | خانة الإقرار |
|------|-------|--------|--------|--------------|
| **P15** | مشتريات خاضعة ١٥٪ | ١٥٪ | **✓ نعم** | مشتريات خاضعة |
| **P0** | مشتريات بنسبة صفر | ٠٪ | — | مشتريات صفرية |
| **PE** | **مشتريات معفاة** | ٠٪ | — | مشتريات معفاة |
| **PND15** | **خاضعة بضريبة غير قابلة للخصم** | ١٥٪ | **✗ لا** | غير قابلة للخصم |
| **POOS** | خارج نطاق الضريبة | ٠٪ | — | خارج النطاق |
| **PFOR0** | مورد أجنبي بلا ضريبة سعودية | ٠٪ | — | مورد أجنبي |
| **PIMPS0** | **واردات معلّقة جمركيًا** | ٠٪ | — | واردات معلّقة |
| **PIMPE** | واردات معفاة | ٠٪ | — | واردات معفاة |

## الفرق الحاسم: `P15` مقابل `PND15`

هذا **أهم تمييز ضريبي في نظامك**، وسوء فهمه يعرّضك للمساءلة.

**فاتورة صيانة بـ١٠٬٠٠٠ + ١٥٠٠ ضريبة:**

| بـ `P15` (قابلة للخصم) | بـ `PND15` (غير قابلة) |
|------------------------|------------------------|
| مصروف صيانة **١٠٬٠٠٠** | مصروف صيانة **١١٬٥٠٠** |
| ضريبة مدخلات **١٥٠٠** | — |
| دائن المورد ١١٬٥٠٠ | دائن المورد ١١٬٥٠٠ |
| **تسترد ١٥٠٠ من الهيئة** | **الضريبة صارت تكلفة** |

**متى تستخدم `PND15`؟**
- ضيافة وترفيه
- سيارات ركوب للاستخدام الشخصي
- مشتريات تخص نشاطًا معفى (تأمين، إيجار سكني)

> **النظام يعالجها صحيحًا تلقائيًا:** الضريبة غير القابلة للخصم **تُضاف لتكلفة البند** ولا تظهر في المدخلات. تحققت من الكود:
> ```
> expense_debit = subtotal + non_deductible_tax
> ```

## `PIMPS0` — الواردات المعلّقة جمركيًا

**لمصنعك تحديدًا.** لو استوردت مواد خامًا بنظام التعليق الجمركي:
- الضريبة **لا تُدفع عند الاستيراد**
- تُسجَّل بالرمز `PIMPS0`
- تظهر في الإقرار بخانة منفصلة

**لو سجّلتها خطأً بـ`P15`** فستطالب باسترداد ضريبة **لم تدفعها** — وهذه مخالفة.

# ثانيًا: الالتزام والضرائب (إقرار القيمة المضافة)

## دورة الإقرار

```
تجميع الفترة → مراجعة الخانات → اعتماد → تقديم لهيئة الزكاة → السداد
```

## الخانات التي يحسبها النظام

**المخرجات (ضريبة المبيعات):**
| الخانة | مصدرها |
|--------|--------|
| مبيعات خاضعة ١٥٪ | فواتير البيع برمز `S15` |
| مبيعات صفرية | `S0` — التصدير |
| مبيعات معفاة | `SE` |
| **آلية الاحتساب العكسي** | `RC` — خدمات مستوردة |

**المدخلات (ضريبة المشتريات):**
| الخانة | مصدرها |
|--------|--------|
| مشتريات خاضعة قابلة للخصم | `P15` |
| **مشتريات غير قابلة للخصم** | `PND15` — **لا تُخصم** |
| واردات | `PIMP15` |
| واردات معلّقة | `PIMPS0` |

**الصافي = المخرجات − المدخلات القابلة للخصم**

- موجب ← **تدفع للهيئة**
- سالب ← **رصيد دائن يُرحَّل أو يُسترد**

## الافتراضيات المهمة

**الفترة الضريبية؟**
شهرية للمنشآت فوق ٤٠ مليون ريال، وربع سنوية لما دونها. **اضبطها في إعدادات الشركة.**

**موعد التقديم؟**
آخر يوم من الشهر التالي لانتهاء الفترة.

**هل يقدّم النظام تلقائيًا للهيئة؟**
**لا.** يجهّز الإقرار وتقدّمه أنت. الربط المباشر بـZATCA يحتاج اعتمادًا رسميًا.

**آلية الاحتساب العكسي — انتبه لها**
عند شراء خدمة من مورد خارج السعودية (استشارات، برمجيات، اشتراكات)، **تُسجّل الضريبة مرتين**: مخرجات ومدخلات معًا. الأثر صفر لو كانت قابلة للخصم، لكن **يجب أن تظهر في الإقرار**.

# ثالثًا: ضريبة الاستقطاع

## متى تُستقطع؟

عند الدفع **لغير مقيم** في السعودية.

| نوع الدفعة | النسبة |
|-----------|--------|
| إتاوات (حقوق ملكية، برمجيات) | **١٥٪** |
| خدمات فنية أو استشارية | **٥٪** |
| إيجار | **٥٪** |
| تذاكر طيران دولي | **٥٪** |
| أرباح أسهم | **٥٪** |
| فوائد قروض | **٥٪** |
| خدمات إدارية لجهة قريبة | **٢٠٪** |

## كيف تعمل

**مثال: استشاري أجنبي بـ١٠٠٬٠٠٠ ريال، خدمة فنية ٥٪**

```
مدين   مصروف استشارات        ١٠٠٬٠٠٠
دائن   ضريبة استقطاع مستحقة     ٥٬٠٠٠
دائن   المورد                  ٩٥٬٠٠٠
```

**تدفع للمورد ٩٥٬٠٠٠ فقط**، وتورّد ٥٬٠٠٠ للهيئة.

## الافتراضيات المهمة

**موعد التوريد؟**
خلال **١٠ أيام** من نهاية الشهر الذي تم فيه الدفع.

**شهادة الاستقطاع؟**
يصدرها النظام للمورد ليستخدمها في بلده لتجنّب الازدواج الضريبي.

**اتفاقيات تجنّب الازدواج؟**
قد تخفّض النسبة. **راجع الاتفاقية مع بلد المورد** — النظام يطبّق النسبة النظامية ما لم تعدّلها يدويًا.

**خطأ شائع:** الاستقطاع يُحسب على **إجمالي الفاتورة** لا على الصافي بعد الضريبة.

# رابعًا: الضريبة الانتقائية

## على ماذا تُطبَّق؟

| المنتج | النسبة |
|-------|--------|
| التبغ ومشتقاته | **١٠٠٪** |
| مشروبات الطاقة | **١٠٠٪** |
| المشروبات الغازية | **٥٠٪** |
| المشروبات المحلّاة | **٥٠٪** |

> **لمصنعك:** لو أنتجت أو استوردت مشروبات محلّاة أو غازية، **هذا القسم يخصك**. أما الدواجن واللحوم فلا انتقائية عليها.

## كيف تُحسب

**الأساس:** أعلى من (سعر البيع للمستهلك − الانتقائية − القيمة المضافة) أو (السعر الاسترشادي المعلن).

**والقيمة المضافة تُحسب بعد الانتقائية** — أي على المبلغ شاملًا الانتقائية.

**مثال: مشروب غازي سعره ١٠ ريالات**
```
السعر قبل الضرائب        ٥٫٨٠
انتقائية ٥٠٪             ٢٫٩٠
الأساس للقيمة المضافة    ٨٫٧٠
قيمة مضافة ١٥٪           ١٫٣٠
الإجمالي                ١٠٫٠٠
```

## الافتراضيات

**الفترة:** كل شهرين.
**التسجيل:** إلزامي قبل أي إنتاج أو استيراد.
**المستودع الضريبي:** يؤجّل الضريبة حتى الإفراج — يحتاج ترخيصًا.

# خامسًا: الزكاة وضريبة الدخل

## أيهما عليك؟

| الحالة | الالتزام |
|--------|---------|
| ملكية سعودية/خليجية ١٠٠٪ | **زكاة فقط** |
| ملكية أجنبية ١٠٠٪ | **ضريبة دخل ٢٠٪** |
| مختلطة | **زكاة على الحصة السعودية + ضريبة على الأجنبية** |

## الوعاء الزكوي

```
+ رأس المال والاحتياطيات
+ الأرباح المبقاة
+ القروض طويلة الأجل
+ المخصصات
− صافي الأصول الثابتة
− الاستثمارات طويلة الأجل
− الخسائر المرحّلة
= الوعاء الزكوي  ×  2.5%
```

**والقاعدة الحاكمة:** الزكاة **لا تقل عن ٢٫٥٪ من صافي الربح المعدّل**.

## ضريبة الدخل

**٢٠٪ من صافي الربح الضريبي** = الربح المحاسبي ± التسويات:

**تُضاف (غير قابلة للخصم):**
- مصروفات شخصية · غرامات · مخصصات غير محققة · ضيافة تتجاوز الحد

**تُخصم:**
- إهلاك ضريبي · خسائر مرحّلة (بحد ٢٥٪ من ربح السنة)

## الافتراضيات

**موعد الإقرار:** خلال **١٢٠ يومًا** من نهاية السنة المالية.
**الشهادة:** تصدرها الهيئة بعد السداد — **مطلوبة للمناقصات وتجديد التراخيص**.
**الدفعات المقدمة:** ثلاث دفعات إن تجاوزت ضريبتك السابقة ٢ مليون.

# سادسًا: المرتجعات والإشعارات الدائنة

## متى تُصدر إشعارًا دائنًا؟

- إرجاع بضاعة
- خصم بعد الفاتورة
- إلغاء صفقة
- تصحيح خطأ في السعر أو الكمية

## القيد

**إشعار دائن ١٠٬٠٠٠ + ضريبة:**
```
مدين   المبيعات               ١٠٬٠٠٠
مدين   ضريبة مخرجات            ١٬٥٠٠
دائن   العميل                 ١١٬٥٠٠
```

## الافتراضيات

**يجب ربطه بالفاتورة الأصلية** — الإشعار المعلّق يعقّد الإقرار.
**يظهر في الإقرار** كتخفيض للمخرجات في **فترة إصداره** لا فترة الفاتورة الأصلية.
**الفوترة الإلكترونية** تشترط رقم الفاتورة الأصلية وسبب الإصدار.
