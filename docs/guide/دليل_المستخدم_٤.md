# أولًا: الأصول الثابتة — IAS 16

## متى يكون الشراء أصلًا لا مصروفًا؟

**ثلاثة شروط معًا:**
1. عمره الإنتاجي **أكثر من سنة**
2. قيمته **فوق حدّ الرسملة** الذي تحدده أنت
3. يُستخدم في النشاط لا للبيع

> **حدّ الرسملة:** ضعه بين **٥٬٠٠٠ و١٠٬٠٠٠ ريال** لمصنعك. كل ما دونه يُصرف مباشرة — لأن تكلفة متابعته تفوق فائدتها.

## تسجيل أصل جديد

| الحقل | ماذا تضع | ملاحظة |
|-------|----------|--------|
| **الاسم** | عربي وإنجليزي | إلزامي |
| **الفئة** | مبانٍ · آلات · سيارات · أثاث · حاسب | تحدد العمر الافتراضي |
| **تاريخ الاقتناء** | تاريخ الشراء | |
| **تاريخ التشغيل** | متى صار **جاهزًا للاستخدام** | **الإهلاك يبدأ من هنا** |
| **التكلفة** | ثمن الشراء + النقل + التركيب + التجربة | |
| **القيمة المتبقية** | المتوقّع عند الاستبعاد | غالبًا صفر |
| **العمر (شهر)** | | انظر الجدول |
| **البنك** | مصدر الدفع | |
| الفرع / مركز التكلفة | اختياري | |

| الفئة | الشهور | السنوات |
|------|--------|---------|
| مبانٍ | ٤٨٠ | ٤٠ |
| آلات ومعدات إنتاج | ١٢٠ | ١٠ |

| حاسب آلي | ٣٦ | ٣ |

## الافتراضيات المهمة

**متى يبدأ الإهلاك؟**
من **تاريخ الجاهزية للاستخدام** — لا من الشراء ولا من التشغيل الفعلي. لو وصلت الماكينة وركّبتها وجرّبتها، **يبدأ الإهلاك** حتى لو لم تُنتج بعد.

**ما الذي يدخل في التكلفة؟**
ثمن الشراء · الجمارك · النقل · التركيب · **تكاليف التجربة قبل التشغيل**.
**ولا يدخل:** التدريب · الترويج · المصاريف الإدارية العامة.

**طريقة الإهلاك؟**
**القسط الثابت** افتراضيًا. القسط المتناقص متاح للأصول التي تفقد قيمتها بسرعة.

**كيف أشغّل الإهلاك؟**
شهريًا من زر **"ترحيل الإهلاك"** مع تحديد التاريخ. القيد:
```
مدين   مصروف إهلاك
دائن   مجمع إهلاك
```

**نسيت شهرًا؟**
شغّله بتاريخ نهاية ذلك الشهر — النظام يحسب المتأخر.

**بيع أصل؟**
من دورة حياة الأصل. الفرق بين المتحصلات والقيمة الدفترية = **ربح أو خسارة استبعاد**.

# ثانيًا: عقود الإيجار — IFRS 16

## القاعدة التي غيّرت كل شيء

**كل عقد إيجار يُثبت في الميزانية** — لم يعد هناك "إيجار تشغيلي" خارج الدفاتر.

**عند التوقيع:**
```
مدين   أصل حق الاستخدام      (القيمة الحالية للدفعات)
دائن   التزام إيجار
```

**شهريًا:**
```
مدين   مصروف إهلاك حق الاستخدام
دائن   مجمع إهلاك حق الاستخدام

مدين   مصروف فوائد
مدين   التزام إيجار
دائن   البنك
```

## تسجيل عقد

| الحقل | ملاحظة |
|-------|--------|
| **تاريخ البدء** | بدء الانتفاع |
| **تاريخ الانتهاء** | نهاية العقد |
| **قيمة الدفعة** | المبلغ الدوري |
| **كل كم شهر** | ١ شهري · ٣ ربعي · ١٢ سنوي |
| **توقيت الدفع** | **بداية** أو **نهاية** الفترة |
| **معدل الخصم %** | **الأهم** — انظر أدناه |

## معدل الخصم — أهم رقم

**ما هو؟** سعر الفائدة الذي لو اقترضت به لاشتريت الأصل بدل استئجاره.

**كيف تحدده؟** اسأل بنكك: *"كم سعر الفائدة على قرض بنفس المدة وبضمان مماثل؟"*

**لماذا يهم؟** يحدد القيمة الحالية — فيغيّر الأصل والالتزام معًا.

> **مثال:** إيجار ١٠٠٬٠٠٠ سنويًا لخمس سنوات
> - بخصم **٥٪** ← أصل والتزام **٤٣٢٬٩٤٨**
> - بخصم **٨٪** ← أصل والتزام **٣٩٩٬٢٧١**
>
> **فرق ٣٣٬٦٧٧ ريال** من رقم واحد.

## الاستثناءات

**لا تُثبت في الميزانية:**
- عقد **أقل من ١٢ شهرًا**
- أصل **منخفض القيمة** (أقل من ٢٠٬٠٠٠ ريال تقريبًا)

هذه تُصرف مباشرة.

# ثالثًا: المصروفات المقدمة

## ما هي؟

دفعت مقدمًا لخدمة **تستهلكها عبر الزمن**: تأمين سنوي، إيجار مدفوع، اشتراكات، رخص.

**عند الدفع:** أصل (`117010`) لا مصروف.
**شهريًا:** يُطفأ جزء ويصير مصروفًا.

## التسجيل

| الحقل | مثال |
|-------|------|
| الاسم | تأمين المصنع ٢٠٢٦ |
| المورد | شركة التأمين |
| **تاريخ الدفع** | ٢٠٢٦/٠١/٠١ |
| **بداية الخدمة** | ٢٠٢٦/٠١/٠١ |
| **نهاية الخدمة** | ٢٠٢٦/١٢/٣١ |
| المبلغ الصافي | ٤٨٬٠٠٠ |
| الضريبة | ١٥٪ |
| **حساب المصروف** | مصروف تأمين |

**النتيجة:** ٤٨٬٠٠٠ ÷ ١٢ = **٤٬٠٠٠ شهريًا**.

## الافتراضيات

**متى أشغّل الإطفاء؟** شهريًا قبل الإقفال.
**فترة غير كاملة؟** يحسب بالتناسب اليومي.
**ألغيت الخدمة؟** أوقف المصروف واعكس الرصيد المتبقي.

# رابعًا: الاستحقاقات

## ما هي؟

**عكس المصروف المقدم**: استهلكت الخدمة ولم تصلك الفاتورة.

**مثال:** كهرباء ديسمبر تصل فاتورتها في يناير. **المصروف يخص ديسمبر** ويجب إثباته فيه.

## التسجيل

| الحقل | مثال |
|-------|------|
| الاسم | استحقاق كهرباء ديسمبر |
| **تاريخ الاستحقاق** | ٢٠٢٦/١٢/٣١ |
| المبلغ | ١٨٬٥٠٠ |
| **حساب مدين** | مصروف كهرباء |
| **حساب دائن** | مصروفات مستحقة |
| **عكس تلقائي** | ✓ نعم |
| **تاريخ العكس** | ٢٠٢٧/٠١/٠١ |

## لماذا العكس التلقائي مهم

بدونه ستُسجَّل المصروف **مرتين**: مرة بالاستحقاق ومرة بالفاتورة.

**بالعكس التلقائي:**
```
٣١ ديسمبر  إثبات الاستحقاق    ١٨٬٥٠٠
١ يناير     عكس تلقائي        (١٨٬٥٠٠)
١٠ يناير    الفاتورة الفعلية    ١٨٬٧٠٠
```
**النتيجة:** ديسمبر يحمل ١٨٬٥٠٠، ويناير يحمل الفرق ٢٠٠ فقط.

## الافتراضيات

**تاريخ العكس المعتاد:** أول يوم في الشهر التالي.
**متى لا أستخدم العكس؟** للاستحقاقات طويلة الأجل (مكافأة نهاية الخدمة) — هذه مخصصات تُراجَع سنويًا.

# خامسًا: مشروعات تحت التنفيذ

## القاعدة المحورية

**العقد لا يُثبت عند التوقيع.** يُسجَّل كالتزام رأسمالي للمتابعة فقط.

**السبب:** الضريبة تُستحق مع المستخلص لا مع التوقيع، وإثبات العقد كاملًا يضخّم الميزانية بأعمال لم تُنفَّذ.

## الدورة

```
مشروع → عقد مقاول → مستخلص → اعتماد → دفع → تحويل لأصل ثابت
```

### القيود

**عند اعتماد المستخلص:**
```
مدين   مشروعات تحت التنفيذ    قيمة الأعمال
مدين   ضريبة مدخلات           الضريبة
دائن   مستحق لمقاولين         (الأعمال + الضريبة − المحتجز)
دائن   محتجز ضمان مقاولين      المحتجز
```

**عند التشغيل:**
```
مدين   الممتلكات والمعدات
دائن   مشروعات تحت التنفيذ
```

## كشف حساب المقاول

يفصل رقمين يُخلط بينهما كثيرًا:

| الرقم | معناه |
|------|-------|
| **المتبقي من العقد** | كم **عملًا** باقيًا على المقاول |
| **الرصيد المستحق** | كم **نقدًا** تدين له الآن |

**مثال حقيقي:** عقد ٢٬٠٠٠٬٠٠٠ · منفّذ ٧٠٠٬٠٠٠
```
المتبقي للتنفيذ    ١٬٣٠٠٬٠٠٠   (٣٥٪ إنجاز)
الضريبة              ١٠٥٬٠٠٠
المحتجز               ٣٥٬٠٠٠
مدفوع                ٥٠٠٬٠٠٠
الرصيد المستحق       ٢٧٠٬٠٠٠
```

## تصنيف التكاليف — تحذير محاسبي

النظام **ينبّه ولا يمنع**:

**تُرسمل:** مواد · عمالة مباشرة · تجهيز موقع · إشراف هندسي · تصاريح · نقل وتركيب · اختبار · تكاليف اقتراض

**تُصرف:** تأسيس · تدريب · مصاريف إدارية · تسويق وافتتاح · هدر غير طبيعي · توقف · خسائر تشغيل تجريبي

> **فرق مهم:** مصاريف تأسيس **الشركة** تُصرف، أما تصاريح البناء وتجهيز موقع **المشروع** فتُرسمل. كثيرون يخلطون بينهما.

## متى تتوقف الرسملة؟

**عند جاهزية الأصل للاستخدام** — لا عند بدء التشغيل الفعلي. لو اكتمل المصنع ولم تشغّله، **يبدأ الإهلاك**.
