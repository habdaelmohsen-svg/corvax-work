# أولًا: الأصناف والمواد الخام

**ابدأ من هنا.** لا تشترِ ولا تُنتج قبل بناء دليل أصنافك.

## أنواع الأصناف

| النوع | يُتابع رصيده؟ | متى تستخدمه |
|------|---------------|-------------|
| **مادة خام** | ✓ نعم | دجاج · توابل · زيوت |
| **منتج تام** | ✓ نعم | ما تبيعه |
| **مواد تغليف** | ✓ نعم | كراتين · أكياس · ملصقات |
| **مخزني** | ✓ نعم | قطع غيار · مستلزمات |
| **مستهلك** | ✗ لا | مواد نظافة · قرطاسية |
| **خدمة** | ✗ لا | صيانة · نقل · استشارات |

> **القاعدة:** لو احتجت معرفة **الكمية المتبقية**، فهو مخزني. وإلا فمستهلك أو خدمة.

## الحسابات الثلاثة — أخطر إعداد في البطاقة

| الحساب | متى يتحرك | المثال |
|--------|-----------|--------|
| **حساب المخزون** | يُدين **عند الاستلام** | `113010` |
| **حساب التكلفة** | يُدين **عند الصرف أو البيع** | `511010` |
| **حساب الإيراد** | يُدان **عند البيع** | `411010` |

> **تحذير:** تغيير هذه الحسابات لاحقًا **لا يصحّح القيود القديمة**. اضبطها من البداية.

## نظام ترقيم مقترح لمصنعك

```
RM-CHK-001    مادة خام — دجاج — تسلسل
RM-SPC-001    مادة خام — توابل
PK-BOX-001    تغليف — كراتين
FG-CHK-001    منتج تام — دجاج
CN-CLN-001    مستهلك — نظافة
```

**لماذا هذا النمط؟** تعرف نوع الصنف من كوده بلا فتح البطاقة، والفرز يجمع المتشابهات.

## الحقول

| الحقل | ملاحظة |
|-------|--------|
| **الكود** | فريد ولا يتغيّر |
| الاسم عربي/إنجليزي | إلزاميان |
| **وحدة القياس** | كجم · طن · صندوق · كرتون · لتر |
| **التكلفة المعيارية** | تقديرية للمقارنة |
| **حد إعادة الطلب** | ينبّهك عند الوصول إليه |

> **حد إعادة الطلب — كيف تحسبه؟**
> `متوسط الاستهلاك اليومي × مدة التوريد بالأيام × ١٫٢`
>
> **مثال:** تستهلك ٥٠٠ كجم يوميًا، والمورد يوصّل خلال ٣ أيام:
> `500 × 3 × 1.2 = 1800 كجم`

# ثانيًا: دورة الشراء الصحيحة

## القاعدة التي يفرضها النظام

```
أمر شراء  →  إثبات استلام  →  فاتورة المورد
   (طلب)      (يزيد المخزون)     (تصفّي الذمة)
```

**النظام يرفض** ترحيل فاتورة شراء مباشرة على حساب المخزون.

### لماذا هذا الرفض صواب

لو سُمح به، لصار المخزون **مدينًا مرتين**: مرة عند الاستلام ومرة عند الفاتورة — بينما الكمية المادية **واحدة**.

**النتيجة:** رصيد الأستاذ لا يطابق المستودع أبدًا، ولا تكتشف الفرق إلا في جرد بعد أشهر.

**رسالة النظام عند المحاولة:**
> *"لا يمكن ترحيل فاتورة شراء على حساب المخزون 113010. المخزون يزيد عند إثبات الاستلام لا عند الفاتورة. الطريق الصحيح: أمر شراء ← إثبات استلام (يزيد المخزون ويسجّل استلامات غير مفوترة 214010) ← ثم فاتورة على 214010 لتصفيته."*

## القيود في كل خطوة

**١) أمر الشراء** — لا قيد. التزام للمتابعة فقط.

**٢) إثبات الاستلام:**
```
مدين   المخزون                 ٢٥٬٠٠٠
دائن   استلامات غير مفوترة      ٢٥٬٠٠٠   ← 214010
```
**وتُسجَّل حركة مخزون فعلية** بالكمية والمستودع والتشغيلة.

**٣) فاتورة المورد:**
```
مدين   استلامات غير مفوترة     ٢٥٬٠٠٠   ← تصفية
مدين   ضريبة مدخلات             ٣٬٧٥٠
دائن   المورد                  ٢٨٬٧٥٠
```

**٤) السداد:**
```
مدين   المورد                  ٢٨٬٧٥٠
دائن   البنك                   ٢٨٬٧٥٠
```

## ما معنى `214010` "استلامات غير مفوترة"؟

**حساب وسيط** يحمل قيمة البضاعة التي **وصلت ولم تُفوتر بعد**.

- يُدان عند الاستلام
- يُدين عند الفاتورة
- **رصيده يجب أن يقارب الصفر** آخر كل شهر

> **مؤشر رقابي:** رصيد كبير في `214010` يعني **بضاعة استُلمت ولم تصل فواتيرها** — راجع الموردين.

## الشراء الخدمي

الصيانة والنقل والاستشارات **لا تمرّ بالمخزون**:
```
مدين   مصروف الصيانة           ٥٬٠٠٠
مدين   ضريبة مدخلات              ٧٥٠
دائن   المورد                   ٥٬٧٥٠
```
اختر **حساب مصروف** مباشرة — والنظام يقبلها.

# ثالثًا: الضريبة في المشتريات

## الرمز يحدد المعالجة

| الرمز | متى | الأثر |
|------|-----|------|
| **P15** | شراء عادي خاضع | الضريبة **تُخصم** |
| **PND15** | ضيافة · سيارات ركوب | **تُضاف للتكلفة** |
| **PE** | تأمين · إيجار سكني | لا ضريبة |
| **PIMPS0** | **واردات معلّقة جمركيًا** | مؤجّلة |
| **PFOR0** | مورد أجنبي | احتساب عكسي |

**النظام يعالجها تلقائيًا** — الضريبة غير القابلة للخصم **تُرسمل في تكلفة البند** ولا تدخل المدخلات.

# رابعًا: الاستيراد والجمارك والتكلفة

## التكلفة الحقيقية للمستورد

**سعر الفاتورة ليس التكلفة.** التكلفة الفعلية:

```
  قيمة البضاعة (FOB)
+ الشحن الدولي
+ التأمين
= القيمة الجمركية (CIF)
+ الرسوم الجمركية (٥٪ عادةً)
+ رسوم الميناء والتخليص
+ النقل الداخلي
+ التخزين المؤقت
= التكلفة الواصلة
```

## توزيعها على الأصناف

**ثلاث طرق:**

| الطريقة | متى تستخدمها |
|---------|--------------|
| **بالقيمة** | أصناف متفاوتة الأسعار |
| **بالوزن** | أصناف ثقيلة متشابهة |
| **بالكمية** | أصناف متجانسة |

> **مثال:** شحنة بتكاليف واصلة ١٥٬٠٠٠ ريال وقيمة بضاعة ١٠٠٬٠٠٠
> صنف قيمته ٤٠٬٠٠٠ يحمل: `40000/100000 × 15000 = 6٬000`
> **فتكلفته الحقيقية ٤٦٬٠٠٠ لا ٤٠٬٠٠٠.**

## الافتراضيات

**لماذا هذا مهم؟** لو حمّلت التكاليف الواصلة على المصروفات بدل تكلفة الصنف، **يظهر مجمل ربحك أعلى من الحقيقة** وتسعّر بالخطأ.

**الواردات المعلّقة:** بنظام التعليق الجمركي لا تُدفع الضريبة عند الاستيراد — سجّلها `PIMPS0`.

# خامسًا: المخزون والمستودعات

## طرق التقييم

| الطريقة | كيف تعمل | لمن |
|---------|----------|-----|
| **المتوسط المرجح** | متوسط متحرك بعد كل استلام | **الافتراضي — الأنسب لك** |
| **الوارد أولًا صادر أولًا** | يصرف الأقدم | للمواد سريعة التلف |
| **التكلفة المعيارية** | ثابتة والفروق تُرحَّل | للإنتاج المستقر |

> **لمصنعك:** **المتوسط المرجح** يناسب الدواجن — الأسعار تتقلب والخلط طبيعي.

## أنواع الحركة

| الحركة | الأثر | القيد |
|--------|------|-------|
| **استلام** | + | مدين مخزون / دائن `214010` |
| **صرف للإنتاج** | − | مدين إنتاج تحت التشغيل / دائن مخزون |
| **بيع** | − | مدين تكلفة المبيعات / دائن مخزون |
| **تحويل** | نقل | مدين مستودع / دائن مستودع |
| **تسوية جرد** | ± | مدين أو دائن فروق الجرد |
| **إتلاف** | − | مدين خسائر تالف / دائن مخزون |

## الجرد

**الدوري:** كل الأصناف مرة أو مرتين سنويًا — يوقف العمل.
**المستمر:** أصناف كل يوم بالتناوب — **أنصح به لمصنعك**.

**عند فرق:**
```
عجز:  مدين خسائر جرد / دائن مخزون
زيادة: مدين مخزون / دائن أرباح جرد
```

> **تحذير:** عجز متكرر في صنف = سرقة أو خطأ وزن أو هدر غير مسجّل. **حقّق فيه.**

## تتبع التشغيلات وتواريخ الصلاحية

**لمصنعك ضرورة لا رفاهية:**
- كل استلام يحمل **رقم تشغيلة** و**تاريخ صلاحية**
- الصرف يتتبع أي تشغيلة خرجت
- **الاستدعاء يصبح ممكنًا:** تعرف أي عميل استلم التشغيلة المعيبة

**تنبيه الصلاحية:** يُنذرك قبل انتهاء الصلاحية بمدة تحددها.
