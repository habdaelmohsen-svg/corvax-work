# أولًا: المبيعات

## دورة البيع

```
عرض سعر → أمر بيع → تسليم → فاتورة → تحصيل
```

**في مصنعك غالبًا:** أمر بيع ← تسليم ← فاتورة ← تحصيل. وعرض السعر للعملاء الجدد أو الصفقات الكبيرة.

## قيود الدورة

**١) الفاتورة:**
```
مدين   العملاء                ١١٥٬٠٠٠
دائن   المبيعات               ١٠٠٬٠٠٠
دائن   ضريبة مخرجات            ١٥٬٠٠٠
```

**٢) تكلفة المبيعات — تلقائية عند خروج البضاعة:**
```
مدين   تكلفة المبيعات          ٧٠٬٠٠٠
دائن   المخزون                 ٧٠٬٠٠٠
```

**٣) التحصيل:**
```
مدين   البنك                  ١١٥٬٠٠٠
دائن   العملاء                ١١٥٬٠٠٠
```

> **مجمل الربح = ١٠٠٬٠٠٠ − ٧٠٬٠٠٠ = ٣٠٬٠٠٠ (٣٠٪)**
> يظهر تلقائيًا **لأن تكلفة الصنف مضبوطة في بطاقته**. ولو أهملت ضبطها، فمجمل ربحك وهم.

## الحقول

| الحقل | ملاحظة |
|-------|--------|
| **العميل** | من دليل العملاء |
| **تاريخ الفاتورة** | يحدد الفترة الضريبية |
| **تاريخ الاستحقاق** | يحدد الأعمار |
| **المرجع** | رقمك أو أمر الشراء من العميل |
| **الأصناف** | كود · كمية · سعر · ضريبة |

## الرموز الضريبية للمبيعات

| الرمز | متى |
|------|-----|
| **S15** | بيع محلي عادي |
| **S0** | **تصدير** — صفري لكن يظهر في الإقرار |
| **SE** | معفى (تأمين · تعليم · صحة) |
| **RC** | احتساب عكسي |

> **خطأ شائع:** تسجيل التصدير كـ`SE` بدل `S0`. الاثنان صفر ضريبة، **لكن التصدير يظهر في خانة مختلفة بالإقرار**، وخلطه يعرّضك لسؤال من الهيئة.

## شروط السداد

| الشرط | المعنى |
|-------|--------|
| نقدي | فورًا |
| صافي ٣٠ | خلال ٣٠ يومًا |
| صافي ٦٠ | خلال ٦٠ يومًا |
| ٢/١٠ صافي ٣٠ | خصم ٢٪ لو دفع خلال ١٠ أيام |

> **نصيحة:** خصم `٢/١٠ صافي ٣٠` يكلّفك ٢٪ لكنه يسرّع التحصيل ٢٠ يومًا. **احسبها:** لو تمويلك يكلّف أكثر من ٣٦٪ سنويًا، فالخصم أرخص.

## الفوترة الإلكترونية

**متطلبات هيئة الزكاة:**
- رقم تسلسلي متصل
- **رمز QR** فيه: اسم البائع · الرقم الضريبي · التاريخ · الإجمالي · الضريبة
- **ختم تشفيري** للمرحلة الثانية
- حفظ ٦ سنوات

> **حالة النظام:** يولّد الفواتير بالحقول المطلوبة. **الربط المباشر مع فاتورة يحتاج شهادة اعتماد** — راجع مزوّد الحلول المعتمد.

## العمولات

**مرحلتان مقصودتان:**

**١) الاستحقاق عند البيع:**
```
مدين   مصروف عمولات            ٣٬٠٠٠
دائن   عمولات مستحقة           ٣٬٠٠٠
```

**٢) الدفع بنسبة التحصيل:**
لو حصّلت ٥٠٪ فقط، **يُدفع ٥٠٪ من العمولة**.

> **لماذا؟** لئلا تدفع عمولة على بيع لم تقبض ثمنه. وهذا **يحفّز المندوب على التحصيل** لا البيع فقط.

**فصل المهام:** مُعِدّ الاستحقاق **لا يعتمده**.

# ثانيًا: العملاء والتسويق

## الحملات

| الحقل | مثال |
|-------|------|
| الكود | `CMP-RMD-2026` |
| الاسم | حملة رمضان |
| **القناة** | رقمي · مباشر · ترشيح · فعالية |
| **الميزانية** | ٦٥٬٠٠٠ |
| البدء والانتهاء | |

## العملاء المحتملون

| الحقل | ملاحظة |
|-------|--------|
| **الحملة** | يربط النتيجة بمصدرها |
| الاسم والبريد | |
| **القيمة المتوقعة** | تقديرك لحجم التعامل |
| **المصدر** | من أين جاء |

> **الفائدة الحقيقية:** حملة بميزانية ٦٥٬٠٠٠ جلبت عملاء بقيمة ٣٤٠٬٠٠٠ = **عائد ٥٫٢ أضعاف**. وحملة بلا نتائج **توقفها**.

## الافتراضيات

**العميل المحتمل ≠ العميل:** لا يدخل الدفاتر حتى يصبح عميلًا فعليًا بفاتورة.
**مراحل الفرصة:** محتمل ← مؤهّل ← عرض ← تفاوض ← ربح/خسارة.

# ثالثًا: المطاعم ونقاط البيع

> يظهر في شركات المطاعم فقط، لا في التصنيع.

## أنواع الطلبات

| النوع | ملاحظة |
|------|--------|
| صالة | مرتبط بطاولة |
| **سفري** | الأكثر شيوعًا |
| توصيل | عبر منصة أو داخلي |
| منصات التوصيل | عمولة تُخصم |

## قيد الطلب

```
مدين   النقد أو البنك أو ذمم المنصة
دائن   إيرادات المطعم
دائن   ضريبة مخرجات
```

**والتكلفة تُحسب من قائمة المواد** لكل صنف.

## منصات التوصيل

**نقطة تُهدر فيها أرباح كثيرة:**
```
مدين   ذمم منصة التوصيل        ٨٥
مدين   مصروف عمولة المنصة      ١٥
دائن   الإيرادات               ١٠٠
```

> **راقب نسبة العمولة.** لو تجاوزت ٢٥٪ فربحك من المنصة قد يكون **سالبًا** بعد التكلفة.

## الورديات

**كل وردية:** رصيد افتتاحي ← مبيعات ← رصيد ختامي ← **فرق الصندوق**.

> **الفرق المتكرر** في وردية كاشير بعينه يحتاج تحقيقًا.

## الافتراضيات

**الضريبة في نقاط البيع:** ١٥٪ افتراضيًا، **والسعر المعروض شامل الضريبة** عادةً.
**الهدر:** سجّله فورًا — يظهر في تقرير الهدر ويصحّح تكلفة الطعام.
**نسبة تكلفة الطعام:** المعيار **٢٨-٣٥٪**. فوق ذلك = هدر أو تسعير خاطئ.

# رابعًا: التحصيل وأعمار العملاء

## تصنيف الذمم

```
٠-٣٠ يوم    ← طبيعي
٣١-٦٠ يوم   ← تابعه
٦٠+ يوم     ← خطر
```

## مؤشرات

**متوسط فترة التحصيل:**
`(الذمم المدينة ÷ المبيعات الآجلة) × ٣٦٥`

> لو النتيجة **٤٥ يومًا** وشروطك **٣٠ يومًا**، فأنت تموّل عملاءك ١٥ يومًا مجانًا.

**نسبة الديون المشكوك فيها:**
راقب ما تجاوز ٩٠ يومًا — يحتاج **مخصصًا**.

## مخصص الديون المشكوك فيها

```
مدين   مصروف ديون مشكوك فيها
دائن   مخصص ديون مشكوك فيها
```

**نسب استرشادية:**

| الفترة | المخصص |
|--------|--------|
| ٠-٦٠ | ٠٪ |
| ٦١-٩٠ | ٥٪ |
| ٩١-١٨٠ | ٢٥٪ |
| ١٨١-٣٦٠ | ٥٠٪ |
| فوق سنة | ١٠٠٪ |

> **للضريبة:** المخصص التقديري **لا يُخصم ضريبيًا**. الخصم عند الشطب الفعلي بشروط الهيئة.
