# أولًا: التصنيع والتكاليف

## قائمة المواد — الأساس

**قبل أي أمر إنتاج، عرّف قائمة المواد (BOM):** ماذا يلزم لإنتاج وحدة من المنتج.

**مثال — كرتون دجاج مقطّع ١٠ كجم:**

| المكوّن | الكمية | الوحدة |
|---------|--------|--------|
| دجاج كامل طازج | ١١٫٥ | كجم |
| كرتون تغليف | ١ | وحدة |
| كيس داخلي | ١٠ | وحدة |
| ملصق | ١ | وحدة |
| توابل | ٠٫٢ | كجم |

> **لاحظ ١١٫٥ كجم لإنتاج ١٠ كجم** — الفرق **نسبة الفاقد الطبيعي** (تقطيع، تنظيف، تصفية). **سجّلها في القائمة** وإلا ظهرت كل شهر كعجز جرد.

## دورة أمر الإنتاج

```
إنشاء الأمر → صرف المواد → التنفيذ → الإقفال
```

### ١) إنشاء الأمر

| الحقل | ملاحظة |
|-------|--------|
| **قائمة المواد** | تحدد المكوّنات |
| **المستودع** | من أين تُصرف |
| **الكمية المخططة** | مثلًا ٧٥٠ كرتونًا |
| التاريخ | |

### ٢) صرف المواد

```
مدين   إنتاج تحت التشغيل       ٢٥٬٠٠٠
دائن   المخزون — مواد خام      ٢٥٬٠٠٠
```
**والكميات تخرج فعليًا** من المستودع بحركة مخزون.

### ٣) الإقفال

| الحقل | ملاحظة |
|-------|--------|
| **الكمية المنتجة** | الفعلية لا المخططة |
| **الساعات الفعلية** | لتحميل العمالة |
| **رقم التشغيلة** | **ضروري للتتبع** |

```
مدين   المخزون — منتج تام      ٢٨٬٥٠٠
دائن   إنتاج تحت التشغيل       ٢٨٬٥٠٠
```

## عناصر التكلفة الثلاثة

| العنصر | كيف يُحمَّل |
|--------|-------------|
| **مواد مباشرة** | من قائمة المواد الفعلية |
| **عمالة مباشرة** | الساعات × معدل الأجر |
| **تكاليف صناعية غير مباشرة** | بمعدل تحميل |

### معدل التحميل

```
معدل التحميل = التكاليف الصناعية المقدرة ÷ أساس التحميل المقدر
```

**مثال:** تكاليف صناعية ٦٠٠٬٠٠٠ سنويًا وساعات إنتاج ٢٤٬٠٠٠
```
٦٠٠٬٠٠٠ ÷ ٢٤٬٠٠٠ = ٢٥ ريالًا لكل ساعة
```

**فأمر استغرق ٤٠ ساعة يحمل ١٬٠٠٠ ريال تكاليف غير مباشرة.**

## الانحرافات — أهم تقرير للمصنع

| الانحراف | المعادلة | معناه |
|---------|----------|-------|
| **سعر المواد** | (فعلي − معياري) × الكمية | المشتريات |
| **كمية المواد** | (فعلية − معيارية) × السعر | الإنتاج/الهدر |
| **معدل الأجر** | (فعلي − معياري) × الساعات | الموارد البشرية |
| **كفاءة العمالة** | (فعلية − معيارية) × المعدل | الإنتاج |

> **الفصل مهم:** انحراف السعر مسؤولية المشتريات، وانحراف الكمية مسؤولية الإنتاج. **لا تحاسب الإنتاج على ارتفاع أسعار الدجاج.**

## كفاءة المعدات OEE

```
OEE = التوافر × الأداء × الجودة
```

| المؤشر | معناه | معيار |
|-------|-------|-------|
| التوافر | وقت التشغيل ÷ المخطط | ٩٠٪ |
| الأداء | الفعلي ÷ الطاقة | ٩٥٪ |
| الجودة | السليم ÷ المنتج | ٩٩٪ |
| **OEE** | | **٨٥٪ ممتاز** |

> **أقل من ٦٠٪** يعني خللًا يستحق التحقيق: أعطال · تغيير خطوط · هدر.

# ثانيًا: الجودة والفحص

## أنواع الفحص

| النوع | متى | يمنع ماذا |
|------|-----|-----------|
| **فحص وارد** | عند الاستلام | دخول مواد معيبة |
| **أثناء الإنتاج** | خلال التشغيل | استمرار خط معطوب |
| **فحص نهائي** | قبل التخزين | خروج منتج معيب |
| **فحص مرتجع** | عند الإرجاع | تحديد السبب |

## تسجيل الفحص

| الحقل | ملاحظة |
|-------|--------|
| **النوع والمصدر** | استلام · أمر إنتاج · مرتجع |
| **الصنف ورقم التشغيلة** | **إلزامي للتتبع** |
| **الكمية المفحوصة** | |
| **المقبولة / المرفوضة** | المجموع = المفحوصة |
| الملاحظات | سبب الرفض |

## معالجة المرفوض

**عند الاستلام:** إرجاع للمورد أو خصم أو قبول مشروط.
```
مدين   المورد
دائن   المخزون
```

**بعد الإنتاج:** إعادة تشغيل أو بيع بدرجة ثانية أو إتلاف.
```
مدين   خسائر إنتاج تالف
دائن   المخزون
```

## مؤشرات

| المؤشر | المعادلة | معيار |
|-------|----------|-------|
| نسبة القبول | المقبول ÷ المفحوص | **> ٩٧٪** |
| نسبة الرفض | المرفوض ÷ المفحوص | **< ٣٪** |
| رفض الموردين | لكل مورد | يقيّم الأداء |

> **مورد نسبة رفضه فوق ٥٪ باستمرار = مورد خاسر** حتى لو كان سعره أرخص.

## حالات عدم المطابقة

**لكل حالة:** الوصف · السبب الجذري · الإجراء التصحيحي · الإجراء الوقائي · المسؤول · الموعد.

> **الفرق:** التصحيحي يعالج الحالة، **والوقائي يمنع تكرارها**. الاكتفاء بالأول يجعلك تكرر المشكلة.

# ثالثًا: سلامة الغذاء وHACCP

> **هذا القسم إلزامي نظاميًا لمصنعك.**

## نقاط التحكم الحرجة

**نقطة حرجة (CCP):** خطوة لو فُقد التحكم فيها يصبح المنتج خطرًا.

**لمصنع الدواجن:**

| النقطة | الحد الحرج | المراقبة |
|--------|-----------|----------|
| **الاستلام** | ≤ ٤°م | كل شحنة |
| **التبريد** | ٠ إلى ٤°م | كل ساعتين |
| **التجميد** | ≤ −١٨°م | كل ساعتين |
| **الطهي** (إن وُجد) | ≥ ٧٤°م بالقلب | كل دفعة |
| **كاشف المعادن** | لا شوائب | كل ساعة |

## سجل المراقبة

| الحقل |
|-------|
| النقطة الحرجة · التاريخ والوقت |
| **القراءة الفعلية** · الحد المسموح |
| **مطابق؟** نعم/لا |
| **الإجراء عند الانحراف** |
| المسؤول · التوقيع |

## عند الانحراف

**خمس خطوات إلزامية:**
1. **عزل المنتج المتأثر فورًا**
2. تحديد السبب
3. الإجراء التصحيحي
4. **تقييم سلامة المنتج**
5. توثيق كل ما سبق

> **مثال:** ارتفعت حرارة غرفة التبريد إلى ٨°م لساعتين ← اعزل ما بها ← أصلح الوحدة ← **قيّم صلاحية المنتج** ← وثّق.

## التتبع والاستدعاء

**التتبع للأمام:** من التشغيلة → أي عميل استلمها
**التتبع للخلف:** من التشغيلة → أي مواد خام دخلتها

> **اختبار الاستدعاء:** يجب أن تتمكن من تتبع أي تشغيلة **خلال ساعتين**. **جرّبه دوريًا** — لا تنتظر أزمة حقيقية.

## النظافة والصيانة الوقائية

**النظافة:** جدول لكل منطقة ومعدة، وسجل يوقّعه المنفّذ والمشرف، **ومسحات دورية** للتحقق.

**الصيانة الوقائية:** جدول لكل معدة **قبل العطل** — وأهمها **معايرة الموازين وأجهزة الحرارة**، لأن قراءة خاطئة تعني تحكمًا وهميًا.
