# أولًا: الصيانة

## سجل الأصول الفنية

**قبل أي أمر صيانة، سجّل معداتك.**

| الحقل | مثال |
|-------|------|
| **الكود** | `MCH-CHL-001` |
| الاسم | غرفة تبريد رقم ١ |
| **الأهمية** | حرجة · عالية · متوسطة · منخفضة |
| الموقع / الفرع | |
| تاريخ التركيب | |

## تصنيف الأهمية — أساس الأولويات

| المستوى | التعريف | المثال في مصنعك |
|---------|---------|-----------------|
| **حرجة** | توقفها يوقف الإنتاج أو يفسد بضاعة | غرف التبريد · خط التقطيع |
| **عالية** | توقفها يبطئ الإنتاج | ماكينة التغليف |
| متوسطة | بديل متاح | ميزان احتياطي |
| منخفضة | لا أثر مباشر | مكيّف المكتب |

> **القاعدة:** الأصل **الحرج** يحتاج صيانة وقائية مجدولة **وقطع غيار مخزّنة**. توقفه ساعة قد يكلّفك شحنة كاملة.

## أنواع الصيانة

| النوع | متى | التكلفة النسبية |
|------|-----|-----------------|
| **وقائية** | مجدولة قبل العطل | **الأرخص** |
| **تنبؤية** | عند مؤشر (اهتزاز · حرارة) | متوسطة |
| **تصحيحية** | بعد العطل | **الأغلى** |
| طارئة | عطل مفاجئ يوقف الإنتاج | الأعلى |

> **قاعدة عملية:** كل ريال في الصيانة الوقائية يوفّر **٤ إلى ٦ ريالات** من التصحيحية. والفارق الحقيقي ليس التكلفة بل **الإنتاج المفقود**.

## أمر الصيانة

| الحقل | ملاحظة |
|-------|--------|
| **الأصل** | من السجل |
| **النوع** | وقائية · تصحيحية · طارئة |
| **الأولوية** | تتبع أهمية الأصل |
| الوصف | العطل أو المهمة |
| **قطع الغيار** | تُصرف من المخزون |
| **ساعات العمل** | للتكلفة |

## القيد

```
مدين   مصروف صيانة            ٣٬٥٠٠
دائن   المخزون — قطع غيار     ٢٬٠٠٠
دائن   أجور مستحقة            ١٬٥٠٠
```

> **متى تُرسمل الصيانة بدل صرفها؟**
> إن كانت **تزيد العمر الإنتاجي** أو **ترفع الطاقة**. أما إعادة الأصل لحالته فتُصرف.
>
> **مثال:** استبدال ضاغط بمثله = **مصروف**. تركيب ضاغط أكبر يرفع الطاقة = **رسملة**.

## مؤشرات

| المؤشر | المعادلة | معناه |
|-------|----------|-------|
| **MTBF** | ساعات التشغيل ÷ عدد الأعطال | متوسط الزمن بين الأعطال |
| **MTTR** | ساعات الإصلاح ÷ عدد الأعطال | متوسط زمن الإصلاح |
| **التوافر** | MTBF ÷ (MTBF + MTTR) | نسبة الجاهزية |

> **مثال:** معدة عملت ٧٢٠ ساعة وتعطلت ٣ مرات باستغراق ١٢ ساعة إصلاح:
> `MTBF = 240` · `MTTR = 4` · **التوافر = ٩٨٫٤٪**

## سلسلة التبريد — نقطة حرجة

**للمنتجات المبردة والمجمدة، درجة الحرارة أثناء النقل جزء من HACCP.**

| المنتج | الحد | التسجيل |
|-------|------|---------|
| دجاج طازج مبرّد | ٠ إلى ٤°م | بداية ونهاية الرحلة |
| دجاج مجمّد | ≤ −١٨°م | نفس الشيء |

> **عند الخروج عن الحد:** عامله كانحراف HACCP — **اعزل الحمولة وقيّم صلاحيتها**. تسليمها دون تقييم مخاطرة قانونية وصحية.

## تكلفة التشغيل

**تكلفة الكيلومتر:**
```
(الوقود + الصيانة + الإهلاك + التأمين + الرواتب) ÷ إجمالي الكيلومترات
```

> **استخدمها في التسعير:** لو كلفة الكيلومتر ٢٫٥ ريال ورحلة التوصيل ٨٠ كم، فتكلفة التوصيل **٢٠٠ ريال** — أضفها لتسعير الطلب أو حدّد حدًا أدنى للطلب.

## الافتراضيات

**استهلاك الوقود:** راقب المعدل لكل مركبة. **قفزة مفاجئة** تعني عطلًا أو تسريبًا أو استخدامًا غير مصرّح.

**الصيانة الدورية:** اربطها بالكيلومترات لا بالتواريخ فقط.

## الاعتراف بالإيراد — نقطة محاسبية مهمة

**العضوية السنوية لا تُعترف كإيراد كاملًا عند البيع.**

```
عند البيع:
مدين   البنك                  ١٢٬٠٠٠
دائن   إيرادات مؤجلة          ١٢٬٠٠٠

شهريًا:
مدين   إيرادات مؤجلة           ١٬٠٠٠
دائن   إيرادات العضويات        ١٬٠٠٠
```

> **لماذا؟** لأنك لم تقدّم الخدمة بعد. الاعتراف الكامل عند البيع **يضخّم إيراد الشهر ويفرغ الأشهر التالية**.

## الحصص والمدربون

**جلسات التدريب الشخصي:** تُباع كباقة وتُستهلك بالجلسة — **نفس منطق الإيراد المؤجل**.

**عمولة المدرب:** تُستحق عند **تنفيذ الجلسة** لا عند بيع الباقة.

## الخزائن والمرافق

**الخزائن:** إيجار دوري بنفس منطق العضوية.
**حجز المرافق:** ملاعب وقاعات — إيراد يُعترف به **عند الاستخدام**.

## مؤشرات

| المؤشر | المعادلة | معيار |
|-------|----------|-------|
| **نسبة التجديد** | المجدّدون ÷ المنتهون | **> ٧٠٪** |
| **معدل الحضور** | الزيارات ÷ الأعضاء | يقيس التفاعل |
| **الإيراد لكل عضو** | الإيراد ÷ عدد الأعضاء | |

> **تحذير:** نسبة تجديد منخفضة مع إيراد مرتفع = **إيراد مؤقت**. تعتمد على عضويات جديدة لتعويض المتسربين، وهذا نموذج هش.
