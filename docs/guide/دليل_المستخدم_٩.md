# أولًا: الموارد والرواتب

## بطاقة الموظف

| الحقل | ملاحظة |
|-------|--------|
| **الرقم الوظيفي** | فريد ولا يتغيّر |
| الاسم عربي/إنجليزي | |
| **الهوية أو الإقامة** | ورقمها |
| **الجنسية** | يؤثر على السعودة والتأمينات |
| **تاريخ التعيين** | يحدد نهاية الخدمة |
| القسم والوظيفة | |
| **الفرع** | يؤثر على تقارير الفروع |
| **الراتب الأساسي** | |
| **البدلات** | سكن · نقل · طبيعة عمل |
| **الحساب البنكي والآيبان** | **إلزامي لحماية الأجور** |

## هيكل الراتب في السعودية

```
  الراتب الأساسي
+ بدل السكن  (٢٥٪ من الأساسي عادةً)
+ بدل النقل  (١٠٪ عادةً)
+ بدلات أخرى
= إجمالي الراتب
− التأمينات الاجتماعية (حصة الموظف)
− السلف والاستقطاعات
= صافي الراتب
```

## التأمينات الاجتماعية

| البند | السعودي | غير السعودي |
|------|---------|-------------|
| المعاشات — المنشأة | ٩٪ | — |
| المعاشات — الموظف | ٩٪ | — |
| **الأخطار المهنية** | ٢٪ | **٢٪** |
| ساند | ٠٫٧٥٪ + ٠٫٧٥٪ | — |
| **إجمالي المنشأة** | **١١٫٧٥٪** | **٢٪** |
| **إجمالي الموظف** | **٩٫٧٥٪** | — |

> **الوعاء:** الراتب الأساسي + بدل السكن، بحد أقصى **٤٥٬٠٠٠ ريال**.

## قيد الرواتب

```
مدين   مصروف رواتب وأجور        ١٠٠٬٠٠٠
مدين   مصروف تأمينات (حصة المنشأة) ١١٬٧٥٠
دائن   رواتب مستحقة              ٩٠٬٢٥٠
دائن   تأمينات مستحقة            ٢١٬٥٠٠
```

**عند الصرف:**
```
مدين   رواتب مستحقة              ٩٠٬٢٥٠
دائن   البنك                     ٩٠٬٢٥٠
```

## مكافأة نهاية الخدمة

**الاستحقاق:**

| المدة | المكافأة |
|------|----------|
| أقل من سنتين | لا شيء (استقالة) |
| ٢ إلى ٥ سنوات | **ثلث** مكافأة المدة |
| ٥ إلى ١٠ سنوات | **ثلثا** المكافأة |
| فوق ١٠ سنوات | **كاملة** |

**الحساب الأساسي:**
```
نصف شهر عن كل سنة من أول ٥ سنوات
+ شهر كامل عن كل سنة بعدها
```

> **محاسبيًا:** يجب **تكوين مخصص شهري** لا انتظار الاستحقاق:
> ```
> مدين   مصروف مكافأة نهاية خدمة
> دائن   مخصص مكافأة نهاية الخدمة
> ```
> **بدونه** تظهر أرباحك أعلى من الحقيقة، وتُفاجأ بمبلغ كبير عند خروج موظف قديم.

## الحضور والانصراف

| الحقل |
|-------|
| الموظف · التاريخ |
| وقت الحضور والانصراف |
| **ساعات إضافية** |
| **حالة** — حاضر · غائب · إجازة · مرضية |

**احتساب الإضافي:** ساعة عادية × ١٫٥ للساعات الإضافية.

## حماية الأجور

**نظام إلزامي:** ترفع ملف الرواتب شهريًا وتطابقه الوزارة مع العقود.

**عند عدم الالتزام:** إيقاف خدمات · منع إصدار تأشيرات · غرامات.

**ما يتحقق منه النظام:**
- كل موظف له آيبان
- الراتب المحوّل = الراتب في العقد
- التحويل خلال المدة النظامية

> **حالة النظام:** يجهّز الملف بالتنسيق المطلوب. **الرفع يتم عبر بوابة الوزارة أو بنكك.**

## القضايا

| الحقل |
|-------|
| رقم القضية والمحكمة |
| الطرف الآخر · الموضوع |
| **المبلغ المتنازع عليه** |
| الحالة · المحامي |

## المعالجة المحاسبية للقضايا

| الاحتمال | المعالجة |
|---------|----------|
| **الخسارة مرجّحة** (>٥٠٪) وقابلة للقياس | **مخصص في الدفاتر** |
| محتملة لكن غير مؤكدة | **إفصاح في الإيضاحات** فقط |
| بعيدة | لا شيء |

```
مدين   مصروف مخصص قضايا
دائن   مخصص التزامات محتملة
```

> **لا تتجاهل قضية مرجّحة الخسارة.** إخفاؤها يجعل قوائمك مضلّلة ويعرّضك للمساءلة.

## التراخيص

| الترخيص | الجهة | التجديد |
|---------|-------|---------|
| السجل التجاري | التجارة | سنوي |
| **رخصة تصنيع غذائي** | **الغذاء والدواء** | حسب النوع |
| رخصة البلدية | الأمانة | سنوي |
| شهادة الزكاة | الزكاة والضريبة | سنوي |
| شهادة السعودة | الموارد البشرية | مستمر |

> **الأخطر:** انتهاء **رخصة التصنيع الغذائي** يوقف الإنتاج فورًا. اضبط تنبيهًا قبل **٩٠ يومًا**.

# ثالثًا: المراجعة والحوكمة

## سجل المخاطر

| الحقل |
|-------|
| وصف الخطر · التصنيف |
| **الاحتمالية** (١-٥) · **الأثر** (١-٥) |
| **الدرجة** = الاحتمالية × الأثر |
| المعالجة · المسؤول · الموعد |

**التعامل حسب الدرجة:**

| الدرجة | التصنيف | الإجراء |
|--------|---------|---------|
| ٢٠-٢٥ | حرج | معالجة فورية |
| ١٢-١٦ | عالٍ | خطة بموعد |
| ٦-١٠ | متوسط | مراقبة |
| ١-٥ | منخفض | قبول |

**أمثلة لمصنعك:**

| الخطر | احتمالية | أثر | درجة |
|-------|---------|-----|------|
| تلوث منتج | ٢ | ٥ | **١٠** |
| عطل غرفة تبريد | ٣ | ٤ | **١٢** |
| انتهاء رخصة | ٢ | ٥ | **١٠** |
| فقد بيانات | ٢ | ٤ | ٨ |

## الضوابط الرقابية

**لكل خطر ضابط:** وقائي (يمنع) · كاشف (يكتشف) · تصحيحي (يعالج).

**أمثلة مطبّقة في نظامك:**
- **وقائي:** فصل المهام — مُعِدّ القيد لا يعتمده
- **وقائي:** منع ترحيل الشراء على المخزون
- **كاشف:** سلسلة تدقيق مؤمّنة بالتجزئة
- **كاشف:** مطابقة الدفاتر الفرعية بالأستاذ

## سجل التدقيق

**كل عملية حساسة تُسجَّل:** المستخدم · الوقت · العملية · القيمة قبل وبعد.

> **السلسلة مؤمّنة بالتجزئة:** كل سجل يحمل بصمة السابق. **أي تعديل أو حذف يكسر السلسلة ويُكتشف فورًا.**

## الملاحظات

**لكل ملاحظة:** الوصف · **السبب الجذري** · التوصية · رد الإدارة · المسؤول · الموعد.

> **الأهم: السبب الجذري.** ملاحظة "خطأ في القيد" بلا سبب جذري تتكرر. أما "خطأ لعدم وجود مراجعة قبل الترحيل" **فتقود لضابط يمنع التكرار**.

# رابعًا: حوكمة الصلاحيات

## المبدأ الحاكم

**أقل صلاحية ممكنة:** يُمنح المستخدم **ما يحتاجه فقط** لأداء عمله — لا أكثر.

## الأدوار المتاحة

| الدور | صلاحياته |
|------|----------|
| **مدير النظام** | كل شيء |
| مدير مالي | المالية والتقارير |
| مراقب مالي | المراجعة والاعتماد |
| **محاسب** | القيود والفواتير — **لا يعتمد** |
| مراجع | قراءة فقط |
| مدير مبيعات | المبيعات والعملاء |
| مدير موارد بشرية | الموظفون والرواتب |
| مدير إنتاج | التصنيع |
| مدير جودة | الفحص وسلامة الغذاء |
| مدير تقنية | الأنظمة والصلاحيات |

## فصل المهام — الضوابط المطبّقة

| العملية | من يُعِدّ | من يعتمد |
|--------|----------|----------|
| قيد يومية | محاسب | مراقب مالي |
| مستخلص مقاول | مهندس | مدير مالي |
| عمولة مندوب | مبيعات | مالي |
| صرف نقدي | محاسب | مدير |

> **النظام يفرضها تقنيًا:** المُعِدّ لا يستطيع اعتماد ما أعدّه — يرفض بـ`403`.

## مراجعة الصلاحيات

**كل ٣ أشهر راجع:**
1. من له صلاحيات أكثر من عمله؟
2. هل بقيت صلاحيات موظف نُقل أو استقال؟
3. هل هناك تعارض في فصل المهام؟
4. من له صلاحية مدير النظام ولماذا؟

> **الأخطر:** حسابات موظفين تركوا العمل ولم تُعطّل. **عطّلها يوم المغادرة لا بعده.**
